# Deployment Methods

## Purpose and scope
Native deployment and container-based deployment. Docker Compose preferred for container-based examples where appropriate.

## Methods
- Native: OS packages, systemd, direct install
- Container-based: Docker Compose for HAProxy/Nginx/Keepalived edge; Helm for in-cluster MetalLB/ingress
