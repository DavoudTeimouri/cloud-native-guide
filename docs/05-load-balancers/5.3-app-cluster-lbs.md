# Application Cluster Load Balancers

## Purpose and scope
Optional dedicated pairs of load balancer nodes for each application cluster. Document when dedicated load balancers are justified vs shared infrastructure sufficient.

## Guidance
- Dedicated LB pair per app cluster: when traffic isolation or scale justifies
- Shared infra LB: acceptable for smaller sites
- MetalLB in-cluster for service LoadBalancer IPs
