# Configuration & Operations

## Purpose and scope

HA configuration, health checks, TLS, backend config, timeouts, connection limits, observability, failover testing, backup, troubleshooting, upgrade procedures.

## Configuration

- HA: Keepalived VIP, HAProxy/Nginx active health checks
- Health checks: TCP/HTTP on backend ports
- TLS: internal CA certs, cert-manager renewal
- Backend config: K8s API, Rancher, Argo CD, monitoring
- Timeouts, connection limits: tuned per service
- Observability: Prometheus scrape, Grafana dashboards
- Failover testing: VIP failover between nodes
- Backup: LB config backed up to Git
- Troubleshooting: common LB failures and resolution
- Upgrade procedures: version compatibility, backup, rollback

## Automation: load balancer playbook

Deploy and configure HAProxy/NGINX via Ansible:

```bash
# Dry-run
ansible-playbook -i automation/ansible/inventories/staging/hosts.ini \
  automation/ansible/playbooks/load-balancer.yml --check --diff

# Apply
ansible-playbook -i automation/ansible/inventories/production/hosts.ini \
  automation/ansible/playbooks/load-balancer.yml

# Limit to specific LB node
ansible-playbook -i automation/ansible/inventories/production/hosts.ini \
  automation/ansible/playbooks/load-balancer.yml --limit lb-nodes
```

**Customization variables** (`automation/ansible/group_vars/all/load-balancer.yml`):

| Variable | Default | Customize when |
| --- | --- | --- |
| `haproxy_frontend_port` | `443` | Change for non-HTTPS frontends |
| `haproxy_backend_servers` | `[]` | List of backend IPs and ports |
| `ssl_certificate_path` | `/etc/haproxy/certs/` | Your cert location differs |
| `health_check_interval` | `2s` | Adjust for faster/slower failover |

**Reverse proxy configuration** per registry (see section 3.5):

| Registry | HAProxy frontend | Backend port | Notes |
| --- | --- | --- | --- |
| Harbor | `harbor.internal:443` | `443` | TLS passthrough, `Docker-Distribution-Api-Version: registry/2.0` header |
| Nexus | `nexus.internal:8443` | `8081` | HTTPS termination at HAProxy |
| GitLab Registry | `registry.gitlab.internal:4443` | `5000` | HTTP backend, do NOT use `https://` to backend |

**Protocols that do NOT work behind reverse proxy** — Git SSH (port 22) connects directly to backend IP; Docker Registry v1 is unsupported (use v2 via Harbor/Nexus).
