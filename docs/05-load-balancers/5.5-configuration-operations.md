# Configuration & Operations

## Purpose and scope

HA configuration, health checks, TLS, backend config, timeouts, connection limits, observability, failover testing, backup, troubleshooting, upgrade procedures.

## Configuration

- HA: Keepalived VIP, HAProxy/Nginx active health checks
- Health checks: TCP/HTTP on backend ports
- TLS: internal CA certs, cert-manager renewal
- Backend config: K8s API, Rancher, Argo CD, monitoring
- Timeouts, connection limits: tuned per service
- Observability: Prometheus scrape, Grafana dashboards
- Failover testing: VIP failover between nodes
- Backup: LB config backed up to Git
- Troubleshooting: common LB failures and resolution
- Upgrade procedures: version compatibility, backup, rollback

## Installation: Docker Compose

### HAProxy via Docker Compose

```bash
# 1. Create directory
mkdir -p /opt/haproxy/{certs,config}

# 2. Copy TLS certificates (from internal CA)
cp /etc/pki/ca-trust/source/anchors/internal-ca.crt /opt/haproxy/certs/
cp /etc/registry/certs/harbor.internal.crt /opt/haproxy/certs/harbor.internal.crt
cp /etc/registry/certs/harbor.internal.key /opt/haproxy/certs/harbor.internal.key

# 3. Combine cert + key into single .pem for HAProxy
cat /opt/haproxy/certs/harbor.internal.crt /opt/haproxy/certs/harbor.internal.key > /opt/haproxy/certs/harbor.internal.pem

# 4. Create docker-compose.yml
cat > /opt/haproxy/docker-compose.yml <<'EOF'
version: '3.8'

services:
  haproxy:
    image: haproxy:2.8
    container_name: haproxy
    restart: unless-stopped
    ports:

      - "80:80"
      - "443:443"
      - "8443:8443"
      - "4443:4443"
    volumes:

      - ./haproxy.cfg:/usr/local/etc/haproxy/haproxy.cfg:ro
      - ./certs:/etc/haproxy/certs:ro
    networks:

      - lb-net

networks:
  lb-net:
    driver: bridge
EOF

# 5. Create haproxy.cfg (full config below)
cat > /opt/haproxy/haproxy.cfg <<'EOF'
global
    log /dev/log local0
    maxconn 4096
    user haproxy
    group haproxy
    daemon

defaults
    log global
    mode tcp
    option tcplog
    option dontlognull
    retries 3
    timeout connect 5000
    timeout client 50000
    timeout server 50000

frontend harbor-frontend
    bind *:443 ssl crt /etc/haproxy/certs/harbor.internal.pem
    mode tcp
    option tcplog
    use_backend harbor-backend

backend harbor-backend
    mode tcp
    balance roundrobin
    option tcplog
    timeout server 600000
    server harbor1 10.10.0.50:443 check fall 3 rise 2

frontend nexus-frontend
    bind *:8443 ssl crt /etc/haproxy/certs/nexus.internal.pem
    mode tcp
    option tcplog
    use_backend nexus-backend

backend nexus-backend
    mode tcp
    balance roundrobin
    option tcplog
    server nexus1 10.10.0.51:8081 check fall 3 rise 2

frontend gitlab-registry-frontend
    bind *:4443 ssl crt /etc/haproxy/certs/gitlab.internal.pem
    mode tcp
    option tcplog
    use_backend gitlab-registry-backend

backend gitlab-registry-backend
    mode tcp
    balance roundrobin
    option tcplog
    server gitlab-registry1 10.10.0.52:5000 check fall 3 rise 2

frontend http-redirect
    bind *:80
    mode http
    reqadd X-Forwarded-Proto:\ http
    default_backend http-https-redirect

backend http-https-redirect
    mode http
    redirect scheme https code 301 if !{ ssl_fc }
EOF

# 6. Start
docker-compose -f /opt/haproxy/docker-compose.yml up -d

# 7. Verify
docker-compose -f /opt/haproxy/docker-compose.yml ps
curl -sk -I https://harbor.internal:443/
```

**Customization hints:**

- Change `haproxy:2.8` to your preferred HAProxy version
- Edit backend server IPs (`10.10.0.50`, `10.10.0.51`, `10.10.0.52`) to match your registry nodes
- Replace certificate paths with your internal cert locations
- Increase `timeout server` for large image uploads

### NGINX via Docker Compose

```bash
# 1. Create directory
mkdir -p /opt/nginx/{certs,config}

# 2. Copy TLS certificates
cp /etc/registry/certs/harbor.internal.crt /opt/nginx/certs/
cp /etc/registry/certs/harbor.internal.key /opt/nginx/certs/

# 3. Create docker-compose.yml
cat > /opt/nginx/docker-compose.yml <<'EOF'
version: '3.8'

services:
  nginx:
    image: nginx:1.25
    container_name: nginx
    restart: unless-stopped
    ports:

      - "80:80"
      - "443:443"
      - "8443:8443"
    volumes:

      - ./nginx.conf:/etc/nginx/nginx.conf:ro
      - ./certs:/etc/nginx/certs:ro
    networks:

      - lb-net

networks:
  lb-net:
    driver: bridge
EOF

# 4. Create nginx.conf
cat > /opt/nginx/nginx.conf <<'EOF'
user nginx;
worker_processes auto;
error_log /var/log/nginx/error.log;
pid /run/nginx.pid;

include /usr/share/nginx/modules/*.conf;

events {
    worker_connections 4096;
    use epoll;
    multi_accept on;
}

http {
    sendfile on;
    tcp_nopush on;
    tcp_nodelay on;
    keepalive_timeout 65;
    types_hash_max_size 2048;

    include /etc/nginx/mime.types;
    default_type application/octet-stream;

    upstream harbor_backend {
        server 10.10.0.50:443;
    }

    upstream nexus_backend {
        server 10.10.0.51:8081;
    }

    upstream gitlab_registry_backend {
        server 10.10.0.52:5000;
    }

    server {
        listen 443 ssl;
        server_name harbor.internal;

        ssl_certificate /etc/nginx/certs/harbor.internal.crt;
        ssl_certificate_key /etc/nginx/certs/harbor.internal.key;
        ssl_protocols TLSv1.2 TLSv1.3;
        ssl_ciphers HIGH:!aNULL:!MD5;

        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header Docker-Distribution-Api-Version "registry/2.0";
        proxy_request_buffering off;
        proxy_buffering off;

        location / {
            proxy_pass https://harbor_backend;
        }
    }

    server {
        listen 8443 ssl;
        server_name nexus.internal;

        ssl_certificate /etc/nginx/certs/harbor.internal.crt;
        ssl_certificate_key /etc/nginx/certs/harbor.internal.key;
        ssl_protocols TLSv1.2 TLSv1.3;
        ssl_ciphers HIGH:!aNULL:!MD5;

        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        location / {
            proxy_pass http://nexus_backend;
        }
    }

    server {
        listen 4443 ssl;
        server_name registry.gitlab.internal;

        ssl_certificate /etc/nginx/certs/harbor.internal.crt;
        ssl_certificate_key /etc/nginx/certs/harbor.internal.key;
        ssl_protocols TLSv1.2 TLSv1.3;
        ssl_ciphers HIGH:!aNULL:!MD5;

        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header Docker-Distribution-Api-Version "registry/2.0";
        proxy_request_buffering off;
        proxy_buffering off;

        location / {
            proxy_pass http://gitlab_registry_backend;
        }
    }

    server {
        listen 80;
        server_name _;
        return 301 https://$host$request_uri;
    }
EOF

# 5. Start
docker-compose -f /opt/nginx/docker-compose.yml up -d

# 6. Verify
docker-compose -f /opt/nginx/docker-compose.yml ps
curl -sk -I https://harbor.internal:443/
```

**Customization hints:**

- Change `nginx:1.25` to your preferred NGINX version
- Edit `upstream` blocks to point at your backend IPs
- Replace certificate paths with your internal cert locations
- Adjust `proxy_buffering`/`proxy_request_buffering` for large image uploads

## Installation: Native (OS packages)

### HAProxy native install (RHEL-family)

```bash
# 1. Install HAProxy
dnf install -y haproxy

# 2. Create configuration directory
mkdir -p /etc/haproxy/certs

# 3. Copy TLS certificates
cp /etc/registry/certs/harbor.internal.crt /etc/haproxy/certs/
cp /etc/registry/certs/harbor.internal.key /etc/haproxy/certs/

# 4. Combine cert + key into single .pem
cat /etc/haproxy/certs/harbor.internal.crt /etc/haproxy/certs/harbor.internal.key > /etc/haproxy/certs/harbor.internal.pem

# 5. Create /etc/haproxy/haproxy.cfg (see Docker Compose section above for full config)
# Copy the haproxy.cfg from the Docker Compose section into /etc/haproxy/haproxy.cfg

# 6. Validate config
haproxy -c -f /etc/haproxy/haproxy.cfg

# 7. Enable and start
systemctl enable --now haproxy

# 8. Verify
systemctl status haproxy
curl -sk -I https://harbor.internal:443/
```

**Customization hints:**

- Edit `/etc/haproxy/haproxy.cfg` backends for your registry IPs
- Change `timeout server` for large image uploads (default 50s, increase to 600s)
- Set certificate paths to match your cert storage location

### Keepalived native install (VIP management)

```bash
# RHEL-family
dnf install -y keepalived

# Ubuntu/Debian
apt-get install -y keepalived

# Create /etc/keepalived/keepalived.conf
cat > /etc/keepalived/keepalived.conf <<'EOF'
vrrp_instance VI_1 {
    state MASTER
    interface eth0
    virtual_router_id 51
    priority 100
    advert_int 1
    virtual_ipaddress {
        10.10.0.10  # LB VIP - change to your VIP
    }
}

vrrp_script chk_haproxy {
    script "pidof haproxy"
    interval 2
    weight 2
}

vrrp_instance VI_1 {
    track_script {
        chk_haproxy
    }
}
EOF

# Enable and start
systemctl enable --now keepalived
```

**Customization hints:**

- Change `interface eth0` to your actual network interface
- Change `virtual_router_id` to a unique number per cluster
- Change `virtual_ipaddress` to your LB VIP
- Change `priority` (100 = master, lower = backup)

## Automation: load balancer playbook

Deploy and configure HAProxy/NGINX via Ansible:

```bash
# Dry-run
ansible-playbook -i automation/ansible/inventories/staging/hosts.ini \
  automation/ansible/playbooks/load-balancer.yml --check --diff

# Apply
ansible-playbook -i automation/ansible/inventories/production/hosts.ini \
  automation/ansible/playbooks/load-balancer.yml

# Limit to specific LB node
ansible-playbook -i automation/ansible/inventories/production/hosts.ini \
  automation/ansible/playbooks/load-balancer.yml --limit lb-nodes
```

**Customization variables** (`automation/ansible/group_vars/all/load-balancer.yml`):

| Variable | Default | Customize when |
| --- | --- | --- |
| `haproxy_frontend_port` | `443` | Change for non-HTTPS frontends |
| `haproxy_backend_servers` | `[]` | List of backend IPs and ports |
| `ssl_certificate_path` | `/etc/haproxy/certs/` | Your cert location differs |
| `health_check_interval` | `2s` | Adjust for faster/slower failover |

**Reverse proxy configuration** per registry (see section 3.5):

| Registry | HAProxy frontend | Backend port | Notes |
| --- | --- | --- | --- |
| Harbor | `harbor.internal:443` | `443` | TLS passthrough, `Docker-Distribution-Api-Version: registry/2.0` header |
| Nexus | `nexus.internal:8443` | `8081` | HTTPS termination at HAProxy |
| GitLab Registry | `registry.gitlab.internal:4443` | `5000` | HTTP backend, do NOT use `https://` to backend |

**Protocols that do NOT work behind reverse proxy** — Git SSH (port 22) connects directly to backend IP; Docker Registry v1 is unsupported (use v2 via Harbor/Nexus).
