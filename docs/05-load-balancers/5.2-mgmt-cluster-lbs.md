# 5.2 Management Cluster Load Balancers

## Purpose and scope
At least two load balancer nodes for management clusters: Kubernetes API, Rancher, Argo CD, monitoring, Grafana, Prometheus, other management services.

## Configuration
- Two LB nodes for HA (Active/Active preferred)
- Kubernetes API VIP (control-plane)
- Rancher, Argo CD, Keycloak, Vault, Prometheus, Grafana VIPs
- Health checks, TLS, failover testing
