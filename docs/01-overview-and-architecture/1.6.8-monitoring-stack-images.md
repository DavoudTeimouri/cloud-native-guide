# Monitoring Stack Images

## Purpose and scope

Monitoring and logging container images: Prometheus, Grafana, Loki, Alertmanager, node exporter. Lists public upstream addresses and internal mirrored Harbor addresses.

## Image addresses

| Component | Image prefix | Public upstream address | Internal mirrored address | Version source |
| --- | --- | --- | --- | --- |
| Prometheus | `quay.io/prometheus/prometheus` | quay.io/prometheus | harbor.internal:5000 | version-matrix |
| Grafana | `docker.io/grafana/grafana` | docker.io/grafana | harbor.internal:5000 | version-matrix |
| Alertmanager | `quay.io/prometheus/alertmanager` | quay.io/prometheus | harbor.internal:5000 | version-matrix |
| Loki | `grafana/loki` | docker.io/grafana | harbor.internal:5000 | version-matrix |
| Promtail | `grafana/promtail` | docker.io/grafana | harbor.internal:5000 | version-matrix |
| Node exporter | `quay.io/prometheus/node-exporter` | quay.io/prometheus | harbor.internal:5000 | version-matrix |

## Validation

- Prometheus targets scrape from internal registry images
- Grafana dashboards load from internal image
- Alertmanager notifications route correctly
