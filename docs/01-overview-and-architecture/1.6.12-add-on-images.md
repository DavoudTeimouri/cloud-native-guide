# 1.6.12 Add-on Images

## Purpose and scope

Kubernetes add-on container images: cert-manager, MetalLB, Velero, Gatekeeper, ExternalDNS. Lists public upstream addresses and internal mirrored Harbor addresses.

## Image addresses

| Component | Image prefix | Public upstream address | Internal mirrored address | Version source |
| --- | --- | --- | --- | --- |
| cert-manager | `quay.io/jetstack/cert-manager-controller` | quay.io/jetstack | harbor.internal:5000 | version-matrix |
| MetalLB | `quay.io/metallb/metallb` | quay.io/metallb | harbor.internal:5000 | version-matrix |
| Velero | `vmware-tanzu/velero` | docker.io/vmwaretanzu | harbor.internal:5000 | version-matrix |
| Gatekeeper | `openpolicyagent/gatekeeper` | docker.io/openpolicyagent | harbor.internal:5000 | version-matrix |
| ExternalDNS | `registry.k8s.io/external-dns` | registry.k8s.io | harbor.internal:5000 | version-matrix |

## Validation

- cert-manager issues certificates from internal CA
- MetalLB allocates IPs from internal image
- Velero backups/restores use internal registry image
