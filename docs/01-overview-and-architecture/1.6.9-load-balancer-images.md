# 1.6.9 Load Balancer Images

## Purpose and scope

Load balancer container images: HAProxy, NGINX, Keepalived. Lists public upstream addresses and internal mirrored Harbor addresses.

## Image addresses

| Component | Image prefix | Public upstream address | Internal mirrored address | Version source |
| --- | --- | --- | --- | --- |
| HAProxy | `docker.io/haproxy/haproxy` | docker.io/haproxy | harbor.internal:5000 | version-matrix |
| NGINX | `docker.io/nginx/nginx` | docker.io/nginx | harbor.internal:5000 | version-matrix |
| Keepalived | `docker.io/osixia/keepalived` | docker.io/osixia | harbor.internal:5000 | version-matrix |

## Validation

- HAProxy config validates against internal image
- Keepalived VIP failover tested with internal image
- Ingress controller deploys from internal registry
