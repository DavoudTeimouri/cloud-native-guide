# 1.5 Deployment Environments

## Purpose and scope
Internet-connected, partially disconnected, fully air-gapped, isolated security zones, upstream/downstream synchronization, DMZ and trusted-zone integration.

## Environment models
| Model | Connectivity | Sync method | Use case |
|---|---|---|---|
| Internet-connected | Full | Direct to public registries | Dev, lab |
| Partially disconnected | Restricted | Proxy, allow-list | Corporate networks |
| Fully air-gapped | None | Physical transfer station | Secure/isolated zones |
| Isolated security zone | None (dedicated) | Staging host + media | High-security |

## Air-gapped synchronization
- Stage artifacts on connected host
- Transfer via physical media to air-gapped transfer station
- Import to internal Harbor/Nexus/GitLab
- All install/upgrade from internal mirrors only
