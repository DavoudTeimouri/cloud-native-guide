# 1.7 Infrastructure Components

## Purpose and scope
Complete component inventory and dependency map.

## Component inventory
| Component | Role | Examples |
|---|---|---|
| Operational servers | Automation, admin, deployment | Linux + Windows mgmt servers |
| Load balancers | North-south, east-west traffic | HAProxy, Nginx, Keepalived |
| Kubernetes clusters | Workload platform | Kubespray, Rancher |
| SDS | Block, file, object storage | Ceph, Rook-Ceph, Longhorn |
| Repositories/registries | Artifact distribution | Harbor, Nexus, GitLab |
| GitLab | Source control, CI/CD | GitLab |
| Monitoring/logging | Observability | Prometheus, Grafana, Loki |
| Identity/secrets | Auth, PKI, secrets | Vault, Keycloak, AD/LDAP |
| Backup | DR, backup | Velero, restic |

## Dependency map
Operational servers → Load balancers → Kubernetes → SDS → Monitoring → Backup
