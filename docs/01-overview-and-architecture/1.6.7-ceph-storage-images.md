# 1.6.7 Ceph & Storage Images

## Purpose and scope

Ceph and Rook-Ceph storage container images: MON, MGR, OSD, MDS, RGW, operator, CSI sidecars. Lists public upstream addresses and internal mirrored Harbor addresses.

## Image addresses

| Component | Image prefix | Public upstream address | Internal mirrored address | Version source |
| --- | --- | --- | --- | --- |
| Ceph MON | `quay.io/ceph/ceph` | quay.io/ceph | harbor.internal:5000 | version-matrix |
| Ceph MGR | `quay.io/ceph/ceph` | quay.io/ceph | harbor.internal:5000 | version-matrix |
| Ceph OSD | `quay.io/ceph/ceph` | quay.io/ceph | harbor.internal:5000 | version-matrix |
| Ceph MDS | `quay.io/ceph/ceph` | quay.io/ceph | harbor.internal:5000 | version-matrix |
| Ceph RGW | `quay.io/ceph/ceph` | quay.io/ceph | harbor.internal:5000 | version-matrix |
| Rook operator | `quay.io/rook/ceph` | quay.io/rook | harbor.internal:5000 | version-matrix |
| Rook CSI sidecar | `quay.io/cephcsi/` | quay.io/cephcsi | harbor.internal:5000 | version-matrix |

## Validation

- `ceph -s` reports HEALTH_OK with images from internal registry
- Rook operator deploys from harbor.internal:5000 only
- CSI sidecars resolve from internal registry
