# 1.6.2 Container Image Registries

## Purpose and scope
Container image registries per component: Kubernetes control plane, Ceph/Rook-Ceph, monitoring, load balancer, GitLab, Rancher, Argo CD, CSI drivers, add-ons. Lists public upstream addresses and internal mirrored Harbor addresses.

## Registry addresses

| Component | Image prefix | Public upstream address | Internal mirrored address | Sync method | Notes |
|---|---|---|---|---|---|
| Container runtime | `docker.io/` | registry-1.docker.io | harbor.internal:5000 | skopeo | Docker Hub rate limits apply upstream |
| Kubernetes control plane | `registry.k8s.io/` | registry.k8s.io | harbor.internal:5000 | skopeo | kube-apiserver, controller-manager, scheduler, etcd |
| Ceph | `quay.io/ceph/` | quay.io/ceph | harbor.internal:5000 | skopeo | Ceph container images |
| Rook-Ceph | `quay.io/rook/` | quay.io/rook | harbor.internal:5000 | skopeo | Rook operator, CSI sidecars |
| Monitoring | `quay.io/prometheus/`, `docker.io/grafana/` | quay.io/prometheus, docker.io/grafana | harbor.internal:5000 | skopeo | Prometheus, Grafana, Loki, Alertmanager |
| Load balancer | `docker.io/haproxy/`, `docker.io/nginx/` | docker.io/haproxy, docker.io/nginx | harbor.internal:5000 | skopeo | HAProxy, NGINX ingress |
| GitLab | `registry.gitlab.com/` | registry.gitlab.com | harbor.internal:5000 | skopeo | GitLab application |
| Rancher | `docker.io/rancher/` | docker.io/rancher | harbor.internal:5000 | skopeo | Management platform |
| Argo CD | `quay.io/argoproj/` | quay.io/argoproj | harbor.internal:5000 | skopeo | GitOps controller, server, dex |
| CSI drivers | `quay.io/ceph/`, `docker.io/` | quay.io/ceph, docker.io | harbor.internal:5000 | skopeo | Rook-Ceph CSI sidecars |
| Add-ons | `quay.io/jetstack/`, `quay.io/metallb/` | quay.io/jetstack, quay.io/metallb | harbor.internal:5000 | skopeo | cert-manager, MetalLB, Velero |

## Internal registry configuration

```bash
# containerd mirror configuration
cat > /etc/containerd/config.toml <<'EOF'
version = 2
[plugins."io.containerd.grpc.v1.cri".registry.mirrors."docker.io"]
  endpoint = ["https://harbor.internal:5000"]
[plugins."io.containerd.grpc.v1.cri"].registry.mirrors."harbor.internal:5000"
  endpoint = ["https://harbor.internal:5000"]
EOF
```

## Validation
- `skopeo inspect docker://harbor.internal:5000/<image>` succeeds
- `crictl pull` / `ctr images pull` uses internal registry only
- No node pulls from public registries at runtime
