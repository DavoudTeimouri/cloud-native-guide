# 1.6.6 Kubernetes Component Images

## Purpose and scope

Kubernetes component container images: control plane, CNI, CSI, storage, and add-on images. Lists public upstream addresses and internal mirrored Harbor addresses.

## Image addresses

| Component | Image prefix | Public upstream address | Internal mirrored address | Version source |
| --- | --- | --- | --- | --- |
| kube-apiserver | `registry.k8s.io/kube-apiserver` | registry.k8s.io | harbor.internal:5000 | version-matrix |
| kube-controller-manager | `registry.k8s.io/kube-controller-manager` | registry.k8s.io | harbor.internal:5000 | version-matrix |
| kube-scheduler | `registry.k8s.io/kube-scheduler` | registry.k8s.io | harbor.internal:5000 | version-matrix |
| kube-proxy | `registry.k8s.io/kube-proxy` | registry.k8s.io | harbor.internal:5000 | version-matrix |
| etcd | `registry.k8s.io/etcd` | registry.k8s.io | harbor.internal:5000 | version-matrix |
| CoreDNS | `registry.k8s.io/coredns` | registry.k8s.io | harbor.internal:5000 | version-matrix |
| Calico CNI | `docker.io/calico/` | docker.io/calico | harbor.internal:5000 | version-matrix |
| Rook-Ceph CSI | `quay.io/cephcsi/` | quay.io/cephcsi | harbor.internal:5000 | version-matrix |
| Metrics Server | `registry.k8s.io/metrics-server` | registry.k8s.io | harbor.internal:5000 | version-matrix |
| Node Feature Discovery | `docker.io/k8sdeviceplugins/` | docker.io/k8sdeviceplugins | harbor.internal:5000 | version-matrix |

## Validation

- `ctr images pull docker://harbor.internal:5000/<image>` succeeds
- Kubespray `container_registry` set to `harbor.internal:5000`
- All cluster pods resolve images from internal registry
