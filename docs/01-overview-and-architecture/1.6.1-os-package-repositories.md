# 1.6.1 OS Package Repositories

## Purpose and scope
OS package repositories per supported distribution: Oracle Linux, Ubuntu, RHEL, Rocky Linux, Debian. Lists public upstream addresses and internal mirrored addresses for connected and air-gapped environments.

## Repository addresses

| Distribution | Repository type | Public upstream address | Internal mirrored address | Sync method | Notes |
|---|---|---|---|---|---|
| Oracle Linux | Base OS + UEK | yum.oracle.com | nexus.internal/repository/yum-oracle | rsync / yum-mirror | Base OS, UEK kernel, Oracle packages |
| Ubuntu | Base OS | archive.ubuntu.com | nexus.internal/repository/ubuntu | apt-mirror | Base OS, security updates |
| RHEL | Base OS | redhat.com | nexus.internal/repository/yum-rhel | subscription mirror | Requires Red Hat entitlement |
| Rocky Linux | Base OS | dl.rockylinux.org | nexus.internal/repository/yum-rocky | rsync / yum-mirror | Base OS, RHEL-compatible |
| Debian | Base OS | deb.debian.org | nexus.internal/repository/debian | apt-mirror | Base OS |

## Internal client configuration

```bash
# Oracle Linux / RHEL / Rocky (DNF/YUM)
cat > /etc/yum.repos.d/internal.repo <<'EOF'
[internal-base]
name=Internal Base Repository
baseurl=http://nexus.internal/repository/yum-oracle
enabled=1
gpgcheck=0
priority=1
EOF

# Ubuntu / Debian (APT)
cat > /etc/apt/sources.list.d/internal.list <<'EOF'
deb http://nexus.internal/repository/ubuntu $(lsb_release -sc) main restricted universe multiverse
EOF
```

## Validation
- `dnf repolist` / `apt-cache policy` shows internal mirrors only
- Package install resolves without public internet
- GPG verification (where enabled) passes against internal keys
