# Network Architecture & Access Matrix

## Purpose and scope
Network segmentation, VLAN/subnet planning, IP allocation, DNS/NTP, routing, firewall, east-west/north-south traffic, reverse proxy, centralized port matrix.

## Network segments
| Segment | Purpose | Examples |
|---|---|---|
| Management | Operational servers, mgmt control plane | 10.10.10.0/24 |
| Control plane | Kubernetes API, etcd | 10.10.20.0/24 |
| Worker | Workload node traffic, pod CIDR | 10.10.30.0/24 |
| Storage | Ceph replication, heartbeat | 10.10.40.0/24 |
| Application | Ingress, north-south traffic | 10.10.50.0/24 |
| DMZ | Public-facing behind reverse proxy | 10.10.60.0/24 |

## DNS & NTP
- Internal DNS for service discovery and infra endpoints
- chrony/ntpd time sync on all nodes; NTP server on operational server

## Firewall
- Host firewalls (firewalld/ufw/iptables) plus network firewalls between segments
- Default deny; allow only matrix-listed ports
