# 1.6.3 Helm Chart Repositories

## Purpose and scope
Helm chart repositories for Kubernetes applications. Lists public upstream chart sources and the internal Helm repository address used by air-gapped environments.

## Chart repository addresses

| Chart source | Public upstream address | Internal mirrored address | Sync method | Charts hosted |
|---|---|---|---|---|
| Bitnami | charts.bitnami.com | harbor.internal:5000/helm | helm repo mirror | NGINX, Redis, PostgreSQL, etc. |
| Prometheus Community | prometheus-community.github.io/charts | harbor.internal:5000/helm | helm repo mirror | Prometheus, Grafana, Loki |
| Argo CD | argo.github.io/argo-cd | harbor.internal:5000/helm | helm repo mirror | Argo CD |
| Rook-Ceph | rook.github.io/charts | harbor.internal:5000/helm | helm repo mirror | Rook-Ceph operator |
| cert-manager | jetstack.github.io/cert-manager | harbor.internal:5000/helm | helm repo mirror | cert-manager |
| MetalLB | metallb.github.io/metallb | harbor.internal:5000/helm | helm repo mirror | MetalLB |
| Velero | vmware-tanzu.github.io/velero | harbor.internal:5000/helm | helm repo mirror | Velero |

## Internal Helm repo configuration

```bash
# Add internal Helm repo
helm repo add internal http://harbor.internal:5000/helm
helm repo update

# Install from internal repo only
helm install prometheus internal/prometheus --namespace monitoring
```

## Validation
- `helm search repo internal` returns charts
- `helm pull internal/<chart>` succeeds without public internet
- Chart provenance verification (where configured) passes
