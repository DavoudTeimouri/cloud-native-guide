# 1.6.4 Git Repositories

## Purpose and scope

Git repositories for code, configuration, IaC, and GitOps. Lists public upstream code hosts and the internal GitLab address used by air-gapped environments.

## Repository addresses

| Repository type | Public upstream address | Internal mirrored address | Sync method | Hosts |
| --- | --- | --- | --- | --- |
| Source code | github.com, gitlab.com | gitlab.internal | git mirror | Application code, IaC, configs |
| GitOps config | github.com | gitlab.internal | git mirror | Argo CD ApplicationSets, Helm values |
| Container registry | registry.gitlab.com | harbor.internal:5000 | skopeo | GitLab container images |

## Internal GitLab configuration

```bash
# Clone from internal GitLab

git clone http://gitlab.internal/infra/kubernetes-manifests.git

# Push to internal GitLab

git remote set-url origin http://gitlab.internal/infra/kubernetes-manifests.git
```

## Validation

- `git clone` / `git fetch` from gitlab.internal succeeds without public internet
- Argo CD syncs from internal Git repo only
- SSH host keys for gitlab.internal pre-seeded on automation server
