# Repositories & Registries

## Purpose and scope
Package repositories, container registries, Helm chart repositories, Git repos, binary/artifact repos, OS-specific repos, Kubernetes component repos, third-party dependencies.

## Repository types
| Type | Purpose | Examples |
|---|---|---|
| OS packages | OS patches, dependencies | YUM, APT, Zypper |
| Container images | Runtime images | Harbor, Nexus, GitLab Registry |
| Helm charts | K8s apps | Harbor, ChartMuseum |
| Git | Code, configs, IaC | GitLab, Gitea |
| Binaries/artifacts | Build artifacts, ISOs | Nexus, Artifactory |

## Upstream/downstream
- Upstream: connected host pulls from public sources
- Downstream: air-gapped pulls from internal mirrors
- Synchronization: scheduled, verified (checksums, signatures)
