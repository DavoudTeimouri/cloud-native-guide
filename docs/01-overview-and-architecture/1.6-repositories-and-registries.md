# 1.6 Repositories & Registries

## Purpose and scope
Package repositories, container registries, Helm chart repositories, Git repos, binary/artifact repos, OS-specific repos, Kubernetes component repos, third-party dependencies. Every component and deployment method that consumes software from a repository or registry is listed below with its public upstream address and its internal mirrored address for air-gapped operation.

## Repository types

| Type | Purpose | Examples |
|---|---|---|
| OS packages | OS patches, dependencies | YUM, APT, Zypper |
| Container images | Runtime images | Harbor, Nexus, GitLab Registry |
| Helm charts | K8s apps | Harbor, ChartMuseum |
| Git | Code, configs, IaC | GitLab, Gitea |
| Binaries/artifacts | Build artifacts, ISOs | Nexus, Artifactory |

## Component & deployment method registry requirements

Each component below lists the public upstream address used by connected environments and the internal mirrored address used by air-gapped/disconnected environments.

| Component / deployment | Repository type | Public upstream address | Internal mirrored address | Sync method | Notes |
|---|---|---|---|---|---|
| Oracle Linux OS packages | OS packages | yum.oracle.com | nexus.internal/repository/yum-oracle | rsync/mirror | Base OS, UEK kernel |
| Ubuntu OS packages | OS packages | archive.ubuntu.com | nexus.internal/repository/ubuntu | apt-mirror | Base OS |
| RHEL OS packages | OS packages | redhat.com | nexus.internal/repository/yum-rhel | subscription mirror | Requires entitlement |
| Rocky Linux OS packages | OS packages | dl.rockylinux.org | nexus.internal/repository/yum-rocky | rsync/mirror | Base OS |
| Container runtime images | Container images | registry-1.docker.io | harbor.internal:5000 | skopeo | Docker Hub |
| Kubernetes control plane images | Container images | registry.k8s.io | harbor.internal:5000 | skopeo | kube-apiserver, scheduler, etc. |
| Ceph / Rook-Ceph images | Container images | quay.io/ceph, quay.io/rook | harbor.internal:5000 | skopeo | SDS platform |
| Monitoring stack images | Container images | quay.io/prometheus, docker.io/grafana | harbor.internal:5000 | skopeo | Prometheus, Grafana, Loki, Alertmanager |
| Load balancer images | Container images | docker.io/haproxy, docker.io/nginx | harbor.internal:5000 | skopeo | HAProxy, NGINX, Keepalived |
| GitLab images | Container images | registry.gitlab.com | harbor.internal:5000 | skopeo | GitLab application |
| Rancher images | Container images | registry.docker.io/rancher | harbor.internal:5000 | skopeo | Management platform |
| Argo CD images | Container images | quay.io/argoproj | harbor.internal:5000 | skopeo | GitOps |
| Helm charts | Helm charts | charts.bitnami.com, prometheus-community.github.io | harbor.internal:5000/helm | helm repo mirror | K8s applications |
| Git repositories | Git | github.com, gitlab.com | gitlab.internal | git mirror | Code, configs, IaC |
| Binary / artifact repositories | Binaries | repo.maven.apache.org, pypi.org | nexus.internal/repository | Nexus proxy | Build artifacts, language packages |
| CSI drivers | Container images | quay.io/ceph, docker.io | harbor.internal:5000 | skopeo | Rook-Ceph CSI |
| Add-on images | Container images | quay.io/jetstack, quay.io/metallb | harbor.internal:5000 | skopeo | cert-manager, MetalLB, Velero |

## Air-gapped synchronization
- Upstream: connected staging host pulls from public upstream addresses listed above.
- Staging: artifacts staged to `/opt/staging` via `scripts/offline-sync.sh`.
- Transfer: physical media to air-gapped transfer station.
- Import: `scripts/air-gapped-import.sh` imports to internal Harbor/Nexus/GitLab.
- All install/upgrade procedures use internal mirrored addresses only; no node requires outbound internet at runtime.
