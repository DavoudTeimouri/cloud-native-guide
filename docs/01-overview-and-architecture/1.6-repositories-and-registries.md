# Repositories & Registries

## Purpose and scope

Package repositories, container registries, Helm chart repositories, Git repos, and binary/artifact repos used by the cloud-native stack. Every public upstream address is listed here; air-gapped environments mirror these internally via the upstream/downstream sync described in section 3.

## Public addresses by component

| Component / deployment | Repository type | Public upstream address |
| --- | --- | --- |
| Oracle Linux OS packages | OS packages | yum.oracle.com |
| Ubuntu OS packages | OS packages | archive.ubuntu.com |
| RHEL OS packages | OS packages | redhat.com |
| Rocky Linux OS packages | OS packages | dl.rockylinux.org |
| Container runtime images | Container images | registry-1.docker.io |
| Kubernetes control plane images | Container images | registry.k8s.io |
| Ceph / Rook-Ceph images | Container images | quay.io/ceph, quay.io/rook |
| Monitoring stack images | Container images | quay.io/prometheus, docker.io/grafana |
| Load balancer images | Container images | docker.io/haproxy, docker.io/nginx |
| GitLab images | Container images | registry.gitlab.com |
| Rancher images | Container images | registry.docker.io/rancher |
| Argo CD images | Container images | quay.io/argoproj |
| Helm charts | Helm charts | charts.bitnami.com, prometheus-community.github.io |
| Git repositories | Git | github.com, gitlab.com |
| Binary / artifact repositories | Binaries | repo.maven.apache.org, pypi.org |
| CSI drivers | Container images | quay.io/ceph, docker.io |
| Add-on images | Container images | quay.io/jetstack, quay.io/metallb |

## Air-gapped synchronization

Connected staging hosts pull from these public addresses. Artifacts are then synced to internal mirrors (Harbor/Nexus/GitLab) and transferred to air-gapped environments via physical media. No node in an air-gapped environment requires outbound internet access at runtime.
