# 1.6.5 Binary & Artifact Repositories

## Purpose and scope

Binary and artifact repositories for build artifacts, ISOs, language packages, and third-party binaries. Lists public upstream sources and internal Nexus addresses.

## Repository addresses

| Artifact type | Public upstream address | Internal mirrored address | Sync method | Notes |
| --- | --- | --- | --- | --- |
| Maven Central | repo.maven.apache.org | nexus.internal/repository/maven | Nexus proxy | Java packages |
| PyPI | pypi.org | nexus.internal/repository/pypi | Nexus proxy | Python packages |
| npm | registry.npmjs.org | nexus.internal/repository/npm | Nexus proxy | Node packages |
| Helm charts | charts.bitnami.com | harbor.internal:5000/helm | helm mirror | See 1.6.3 |
| Build artifacts | — | nexus.internal/repository/artifacts | Local upload | Internal builds |
| ISOs / OS media | vendor sites | nexus.internal/repository/iso | Manual upload | OS installation media |
| Kubespray | github.com | gitlab.internal | git mirror | Kubernetes installer |

## Internal Nexus configuration

```bash
# Configure pip to use internal PyPI

cat > /etc/pip.conf <<'EOF'
[global]
index-url = http://nexus.internal/repository/pypi/simple
trusted-host = nexus.internal
EOF

# Configure npm to use internal registry

npm config set registry http://nexus.internal/repository/npm
```

## Validation

- `pip install` / `npm install` resolves from internal Nexus only
- `curl http://nexus.internal/repository/` returns repository listing
- Artifact checksums verified after sync
