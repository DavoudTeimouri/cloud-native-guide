# 1.6.11 Rancher & Argo CD Images

## Purpose and scope
Management platform and GitOps container images: Rancher, Argo CD controller/server/dex. Lists public upstream addresses and internal mirrored Harbor addresses.

## Image addresses

| Component | Image prefix | Public upstream address | Internal mirrored address | Version source |
|---|---|---|---|---|
| Rancher | `docker.io/rancher/rancher` | docker.io/rancher | harbor.internal:5000 | version-matrix |
| Argo CD server | `quay.io/argoproj/argocd` | quay.io/argoproj | harbor.internal:5000 | version-matrix |
| Argo CD dex | `quay.io/argoproj/argocd-dex` | quay.io/argoproj | harbor.internal:5000 | version-matrix |
| Argo CD repo server | `quay.io/argoproj/argocd-repo-server` | quay.io/argoproj | harbor.internal:5000 | version-matrix |

## Validation
- Rancher deploys from harbor.internal:5000
- Argo CD syncs applications from internal Git repo
- Management cluster accessible via internal LB
