# Standards & Best Practices

## Purpose and scope
Security standards, Kubernetes standards, storage standards, networking standards, operational standards, documentation standards, compliance.

## Standards
| Domain | Standard | Notes |
|---|---|---|
| Security | CIS, NIST, PCI-DSS where applicable | Least privilege, TLS everywhere |
| Kubernetes | CIS Kubernetes, Pod Security Standards | Restricted PSA |
| Storage | CSI, CSI sidecar | Rook-Ceph CSI |
| Networking | CNI, NetworkPolicy | Calico + policies |
| Operational | ITIL-lite change, incident, problem | Checklists, maintenance windows |
| Documentation | This guide | MkDocs, Material theme |

## Compliance
- Audit logging enabled on K8s API
- Access reviews quarterly
- Certificate inventory maintained
