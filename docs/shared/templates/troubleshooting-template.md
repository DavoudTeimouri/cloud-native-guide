# Troubleshooting template

## Purpose
Document a troubleshooting scenario for an infrastructure component.

## Sections
1. Symptoms
2. Possible causes
3. Diagnostic commands
4. Expected output
5. Investigation procedure
6. Resolution
7. Verification
8. Prevention

## Placeholders
- `<COMPONENT>`, `<SYMPTOM>`, `<COMMAND>`, `<EXPECTED_OUTPUT>`, `<RESOLUTION>`
