# Maintenance template

## Purpose
Document recurring operational procedures for a component.

## Sections
1. Component and schedule (daily/weekly/monthly/quarterly)
2. Procedure steps
3. Prerequisites and dependencies
4. Validation after maintenance
5. Rollback / recovery if procedure fails
6. Evidence record

## Placeholders
- `<COMPONENT>`, `<SCHEDULE>`, `<PROCEDURE>`, `<EVIDENCE_PATH>`
