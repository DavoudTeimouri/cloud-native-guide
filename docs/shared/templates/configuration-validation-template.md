# Configuration validation template

## Purpose
Validate that a component is configured correctly after deployment.

## Sections
1. Component and version
2. Configuration files checked
3. Expected values vs actual values
4. Validation commands and expected output
5. Pass/fail criteria
6. Evidence reference (links to tests/acceptance/)

## Placeholders
- `<COMPONENT>`, `<VERSION>`, `<CONFIG_FILE>`, `<EXPECTED_VALUE>`, `<EVIDENCE_PATH>`
