# Backup & recovery template

## Purpose
Document backup and recovery for a component.

## Sections
1. Component and what is backed up
2. Backup mechanism, schedule, retention
3. Storage location (on-site / off-site / air-gapped media)
4. RPO and RTO targets
5. Restore procedure
6. Validation (restore drill) and evidence
7. Encryption and access control

## Placeholders
- `<COMPONENT>`, `<RPO>`, `<RTO>`, `<STORAGE_LOCATION>`, `<EVIDENCE_PATH>`
