# Upgrade planning template

## Purpose
Plan a component upgrade safely.

## Sections
1. Component and current version
2. Target version and compatibility check (against shared version & compatibility matrix)
3. Upgrade order and dependencies
4. Prerequisites and backup
5. Pre-upgrade validation
6. Execution steps
7. Post-upgrade validation
8. Rollback strategy and downtime
9. Air-gapped considerations (if applicable)

## Rule
Never recommend an upgrade without checking component compatibility and supported upgrade paths.

## Placeholders
- `<COMPONENT>`, `<CURRENT_VERSION>`, `<TARGET_VERSION>`, `<ROLLBACK_PLAN>`
