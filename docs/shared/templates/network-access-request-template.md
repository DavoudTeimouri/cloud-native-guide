# Network access request template

## Purpose
Request network access (firewall rule) between two components in the Cloud-Native stack.

## Fields
- Request ID, requester, date, environment
- Source component / role / network
- Destination component / role / network
- Protocol, port, direction
- Purpose, required/optional
- Related documentation link
- Firewall implementation notes
- Approver, approval date

## Placeholders
- `<SOURCE>`, `<DEST>`, `<PROTOCOL>`, `<PORT>`, `<ENVIRONMENT>`, `<PURPOSE>`
