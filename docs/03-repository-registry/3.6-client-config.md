# Client Configuration

## Purpose and scope

Configuration examples for all relevant clients: DNF/YUM, APT, Docker, containerd, Helm, Git, pip, npm, Maven, NuGet, Cargo. The target is to use original addresses where possible, using the reverse proxy as the single entry point. If a protocol cannot work behind a reverse proxy, real configuration examples document the direct connection alternative.

## General principle

| Principle | Guidance |
| --- | --- |
| Original addresses preferred | Clients should connect to `harbor.internal`, `nexus.internal`, `gitlab.internal` via reverse proxy where possible |
| Reverse proxy as single entry point | All HTTPS traffic (443/8443/4443) terminates at HAProxy/NGINX |
| Direct connection exception | Protocols that cannot work behind reverse proxy (Git SSH, Docker Registry v1) connect directly to backend IP |
| Air-gapped | All clients point to internal mirrors only; no public internet access |

## DNF/YUM (OS packages)

### Via Nexus reverse proxy (preferred)

```bash

# /etc/yum.repos.d/internal.repo

[internal-nexus]
name=Internal Nexus Repository
baseurl=https://nexus.internal:8443/repository/maven-public/
enabled=1
gpgcheck=0
sslverify=1
sslcacert=/etc/pki/ca-trust/source/anchors/internal-ca.crt

[internal-nexus-rpm]
name=Internal Nexus RPM Repository
baseurl=https://nexus.internal:8443/repository/rpm-public/
enabled=1
gpgcheck=0
sslverify=1
sslcacert=/etc/pki/ca-trust/source/anchors/internal-ca.crt
```

```bash

# Verify

dnf repolist
dnf install -y <package>
```

### Alternative: Direct to backend (if reverse proxy not available)

```bash
[internal-nexus-direct]
name=Internal Nexus Direct
baseurl=http://10.10.0.51:8081/repository/maven-public/
enabled=1
gpgcheck=0
```

## APT (Debian/Ubuntu packages)

### Via Nexus reverse proxy (preferred)

```bash

# /etc/apt/sources.list.d/internal.list

deb https://nexus.internal:8443/repository/debian-public/ bookworm main contrib non-free
deb-src https://nexus.internal:8443/repository/debian-public/ bookworm main contrib non-free
```

```bash

# Add internal CA to apt trusted keys

cp /etc/pki/ca-trust/source/anchors/internal-ca.crt /usr/local/share/ca-certificates/internal-ca.crt
update-ca-certificates

# Verify

apt-get update
apt-get install -y <package>
```

## Docker / containerd (container images)

### Via Harbor reverse proxy (preferred)

```bash

# /etc/docker/daemon.json

{
  "registry-mirrors": [
    "https://harbor.internal:443"
  ]
}
```

```bash

# Restart Docker

systemctl restart docker

# Verify

docker login harbor.internal:443 -u admin -p <password>
docker pull harbor.internal:5000/library/alpine:3.19
```

### containerd configuration

```bash

# /etc/containerd/config.toml

[plugins."io.containerd.grpc.v1.cri".registry.mirrors."docker.io"]
  endpoint = ["https://harbor.internal:443"]

[plugins."io.containerd.grpc.v1.cri".registry.mirrors."quay.io"]
  endpoint = ["https://harbor.internal:443"]

[plugins."io.containerd.grpc.v1.cri".registry.mirrors."gcr.io"]
  endpoint = ["https://harbor.internal:443"]
```

```bash

# Restart containerd

systemctl restart containerd
```

## Helm charts

### Via Harbor reverse proxy (preferred)

```bash

# Add Harbor as Helm repo

helm repo add harbor https://harbor.internal:443/chartrepo/library
helm repo update

# Verify

helm search repo harbor

# Install from Harbor

helm install my-app harbor/my-app
```

### Alternative: Direct to Harbor backend

```bash
helm repo add harbor-direct https://10.10.0.50:443/chartrepo/library
```

## Git repositories

### Via GitLab reverse proxy (preferred - HTTP/HTTPS)

```bash

# Clone via HTTPS through reverse proxy

git clone https://gitlab.internal/group/project.git

# Configure Git to use internal GitLab

git config --global url."https://gitlab.internal/".insteadOf "https://github.com/"
```

### Direct connection (SSH - cannot go through HTTP reverse proxy)

```bash

# SSH clone (direct to GitLab backend IP, bypassing reverse proxy)

git clone ssh://git@10.10.0.52:22/group/project.git

# Or configure SSH config

cat ~/.ssh/config
Host gitlab.internal
    HostName 10.10.0.52
    Port 22
    User git
    IdentityFile ~/.ssh/id_ed25519
```

```bash

# Clone via SSH config

git clone git@gitlab.internal:group/project.git
```

## pip (Python packages)

### Via Nexus reverse proxy (preferred)

```bash

# /etc/pip.conf

[global]
index-url = https://nexus.internal:8443/repository/pypi-public/simple
trusted-host = nexus.internal

# Or per-user

mkdir -p ~/.config/pip
cat > ~/.config/pip/pip.conf <<'EOF'
[global]
index-url = https://nexus.internal:8443/repository/pypi-public/simple
trusted-host = nexus.internal
EOF

# Verify

pip install <package>
```

## npm (Node.js packages)

### Via Nexus reverse proxy (preferred)

```bash

# Global npm config

npm config set registry https://nexus.internal:8443/repository/npm-public/

# Or per-project

cat .npmrc
registry=https://nexus.internal:8443/repository/npm-public/

# Verify

npm install <package>
```

## Maven

### Via Nexus reverse proxy (preferred)

```bash

# ~/.m2/settings.xml

<settings>
  <mirrors>
    <mirror>
      <id>internal-nexus</id>
      <mirrorOf>*</mirrorOf>
      <url>https://nexus.internal:8443/repository/maven-public/</url>
    </mirror>
  </mirrors>
  <profiles>
    <profile>
      <id>internal</id>
      <repositories>
        <repository>
          <id>internal-nexus</id>
          <url>https://nexus.internal:8443/repository/maven-public/</url>
          <releases>
            <enabled>true</enabled>
          </releases>
          <snapshots>
            <enabled>false</enabled>
          </snapshots>
        </repository>
      </repositories>
    </profile>
  </profiles>
  <activeProfiles>
    <activeProfile>internal</activeProfile>
  </activeProfiles>
</settings>

# Verify

mvn dependency:get -Dartifact=org.apache.maven.plugins:maven-jar-plugin:3.3.0
```

## NuGet (.NET packages)

### Via Nexus reverse proxy (preferred)

```bash

# Global NuGet config

dotnet nuget add source https://nexus.internal:8443/repository/nuget-public/index.json --name internal-nexus

# Or per-project (nuget.config)

cat nuget.config
<?xml version="1.0" encoding="utf-8"?>
<configuration>
  <packageSources>
    <add key="internal-nexus" value="https://nexus.internal:8443/repository/nuget-public/index.json" />
  </packageSources>
</configuration>

# Verify

dotnet restore
dotnet add package <package>
```

```bash
# ~/.cargo/config.toml
```

## Air-gapped client configuration

In air-gapped environments, all clients must point to internal mirrors only:

```bash

# Example: Complete air-gapped client configuration

# YUM/DNF - point to internal Nexus only

cat /etc/yum.repos.d/internal.repo
[internal-nexus]
baseurl=https://nexus.internal:8443/repository/maven-public/
gpgcheck=0

# Docker/containerd - point to internal Harbor only

cat /etc/containerd/config.toml
[plugins."io.containerd.grpc.v1.cri".registry.mirrors."docker.io"]
  endpoint = ["https://harbor.internal:443"]
[plugins."io.containerd.grpc.v1.cri".registry.mirrors."quay.io"]
  endpoint = ["https://harbor.internal:443"]
[plugins."io.containerd.grpc.v1.cri".registry.mirrors."gcr.io"]
  endpoint = ["https://harbor.internal:443"]

# npm - point to internal Nexus only

npm config set registry https://nexus.internal:8443/repository/npm-public/

# pip - point to internal Nexus only

pip config set global.index-url https://nexus.internal:8443/repository/pypi-public/simple

# Verify no public internet access

curl -I https://docker.io 2>&1 | head -1  # Should fail
curl -I https://harbor.internal:443  # Should succeed
```
