# 3.6 Client Configuration

## Purpose and scope
Configuration examples for all relevant clients: DNF/YUM, APT, Docker, containerd, Helm, Git, pip, npm, Maven, NuGet, Cargo — through internal repos.

## Examples
- DNF/YUM: baseurl pointing to internal Nexus
- APT: sources.list pointing to internal Nexus
- Docker/containerd: registry mirrors pointing to internal Harbor
- Helm: --repository pointing to internal Helm chart repo
- Git: remote pointing to internal GitLab
- pip/npm/Maven/NuGet/Cargo: index pointing to internal Nexus
