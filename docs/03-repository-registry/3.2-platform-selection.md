# Platform Selection

## Purpose and scope

Compare Nexus Repository, Harbor, GitLab, and other artifact/container repository solutions. Explain which platform manages each artifact type. **No single product supports every protocol and workflow** — each platform has strengths and limitations, and most production environments run two or three platforms in parallel.

## Platform comparison matrix

| Technology | Type | Best for | Protocols supported | Offline/air-gapped | HA support | Scan/verify |
| --- | --- | --- | --- | --- | --- | --- |
| Harbor | Container + OCI registry | Container images, Helm charts, OCI artifacts | Docker/OCI, Helm, ChartMuseum | Yes (proxy + air-gapped sync) | Yes (primary/secondary) | Yes (Clair/Trivy, Cosign, Notary) |
| Nexus Repository | Package repository | RPM, DEB, Maven, PyPI, npm, NuGet, Cargo, generic | YUM/APT, Maven, PyPI, npm, NuGet, Cargo, Raw, Docker/OCI | Yes (proxy + air-gapped sync) | Yes (Nexus Pro/HA) | Yes (Nexus IQ, CLM) |

| JFrog Artifactory | Universal repository | All package types (commercial) | Docker/OCI, Helm, Maven, PyPI, npm, NuGet, Cargo, RPM, DEB | Yes (proxy + air-gapped) | Yes (HA) | Yes (Xray) |
| Apache Archiva | Maven repository | Maven artifacts only | Maven | Yes (proxy) | Limited | No |
| JFrog Distribution | Release distribution | Release artifact distribution | Docker/OCI, Helm, generic | Yes (air-gapped) | Yes | Yes |

## Selection guidance

### No single product does everything

**Important:** No single repository platform natively supports every protocol and workflow at enterprise grade. Harbor excels at container images and OCI artifacts but is weak at OS packages (RPM/DEB). Nexus excels at OS and language packages but its container registry is secondary to Harbor's. GitLab excels at Git and CI/CD artifacts but its container registry lacks Harbor's scanning and replication features.

Most production environments run **two or three platforms in parallel**:

| Artifact type | Recommended platform | Alternative |
| --- | --- | --- |
| Container images (Docker/OCI) | Harbor | GitLab Container Registry, Artifactory |
| Helm charts | Harbor | Nexus, Artifactory |
| OS packages (RPM, DEB) | Nexus | Artifactory, JFrog Distribution |
| Language packages (Maven, PyPI, npm, NuGet, Cargo) | Nexus | Artifactory, CloudRepo |
| Git repositories + CI/CD artifacts | GitLab | GitHub Enterprise, Bitbucket |
| Release artifacts (versioned, signed) | JFrog Distribution | Harbor replication |

### Selection criteria

| Criterion | Harbor | Nexus | GitLab | Artifactory |
| --- | --- | --- | --- | --- |
| Container image scanning | Built-in (Clair/Trivy) | Via Nexus IQ | Via Dependency Scanning | Built-in (Xray) |
| OCI artifact support | Native | Via Docker/OCI repos | Via Container Registry | Native |
| Helm chart repository | Native | Via raw/helm repos | Via project export | Native |
| OS package proxy (RPM/DEB) | No | Native | No | Native |
| Language package proxy | No | Native | No | Native |
| Git repository | No | No | Native | No |
| CI/CD integration | Limited | Limited | Native | Limited |
| Air-gapped sync | Replication + export | Replication + export | Mirror + package registry | Replication + distribution |
| Multi-project RBAC | Native | Native (Pro) | Native | Native |
| Cost | Open source | OSS (free), Pro (paid) | Free (self-managed) | Commercial |
