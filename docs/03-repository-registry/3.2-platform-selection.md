# 3.2 Platform Selection

## Purpose and scope
Compare Nexus Repository, Harbor, and other artifact/container repository solutions. Explain which platform manages each artifact type. Do not assume one product supports every protocol/workflow.

## Comparison
| Technology | Type | Best for | Offline |
|---|---|---|---|
| Harbor | Container registry | Images, OCI charts | Yes |
| Nexus | Package repo | RPM/DEB/APT/Maven | Yes |
| GitLab | Git repo | Source, CI/CD | Yes (mirror) |

## Selection
- Harbor: images and OCI charts (primary container registry)
- Nexus: OS packages and language packages (primary package repo)
- GitLab: source and pipeline storage (primary Git repo)
- One owner per artifact type
