# Installation & Configuration

## Purpose and scope

Native and container-based installation for Harbor, Nexus Repository, and GitLab. Includes Docker Compose (preferred for air-gapped), Helm charts, native packages, persistent storage, HA/scalability, backup/restore, auth, TLS, monitoring, logging, and upgrades. All procedures work in connected and air-gapped environments.

## Prerequisites (all platforms)

### System requirements

| Platform | CPU | RAM | Disk | OS |
| --- | --- | --- | --- | --- |
| Harbor (small) | 4 vCPU | 8 GB | 100 GB | Oracle Linux 9+, Ubuntu 24.04 LTS |
| Harbor (production) | 8 vCPU | 16 GB | 500 GB+ | Oracle Linux 9+, Ubuntu 24.04 LTS |
| Nexus (small) | 4 vCPU | 4 GB | 100 GB | Oracle Linux 9+, Ubuntu 24.04 LTS |
| Nexus (production) | 8 vCPU | 16 GB | 1 TB+ | Oracle Linux 9+, Ubuntu 24.04 LTS |
| GitLab (small) | 8 vCPU | 16 GB | 200 GB | Oracle Linux 9+, Ubuntu 24.04 LTS |
| GitLab (production) | 16 vCPU | 32 GB | 1 TB+ | Oracle Linux 9+, Ubuntu 24.04 LTS |

### Common pre-installation steps

```bash

# 1. Prepare OS (see section 02.5 OS Preparation by Role)

# 2. Install Docker Compose

dnf install -y docker-compose   # RHEL-family
apt-get install -y docker-compose  # Ubuntu/Debian

# 3. Create installation directory

mkdir -p /opt/registry/{harbor,nexus,gitlab}
cd /opt/registry

# 4. Set up internal CA certificates

cp /etc/pki/ca-trust/source/anchors/internal-ca.crt /etc/docker/certs.d/harbor.internal:5000/ca.crt
systemctl restart docker containerd
```

## Harbor installation

### Option A: Docker Compose (preferred for air-gapped)

```bash

# 1. Download Harbor installer on connected staging host

curl -L https://github.com/goharbor/harbor/releases/download/v2.10.0/harbor-offline-installer-v2.10.0.tgz -o harbor-installer.tgz
tar xzf harbor-installer.tgz
cd harbor

# 2. Configure Harbor

cat > harbor.yml <<'EOF'
hostname: harbor.internal

http:
  port: 8080

https:
  port: 443
  certificate: /etc/registry/certs/harbor.internal.crt
  private_key: /etc/registry/certs/harbor.internal.key

harbor_admin_password: Harbor12345

database:
  password: root123
  max_idle_conns: 50
  max_open_conns: 100

redis:
  password: redis123

registry:
  credential: credential
  addr: harbor.internal:5000

trivy:
  enabled: true
  skip_java_verify: false

notary:
  enabled: false

chartserver:
  enabled: true

log:
  level: info
  local:
    rotate_count: 50
    rotate_size: 50M
    location: /var/log/harbor

version: 2.10.0

proxy:
  http_proxy: http://proxy.internal:3128
  https_proxy: http://proxy.internal:3128
  no_proxy: localhost,127.0.0.1,.internal,.svc
  components:
    - core
    - jobservice
    - trivy
EOF

# 3. Prepare configuration

./prepare.sh

# 4. Install Harbor

./install.sh --with-clair --with-trivy --with-chartmuseum
```

**Docker Compose alternative (minimal, no Clair):**

```bash

# Minimal compose without Clair for air-gapped

./prepare.sh --without-clair --without-trivy --without-chartmuseum
./install.sh
```

### Option B: Helm chart (connected environments only)

```bash

# 1. Add Harbor Helm repo on connected host

helm repo add harbor https://helm.goharbor.io
helm repo update

# 2. Package chart for air-gapped transfer

helm package harbor/harbor --version 2.10.0

# Transfer harbor-2.10.0.tgz to air-gapped environment

# 3. Install on air-gapped environment

helm install harbor harbor/harbor \
  --namespace harbor \
  --create-namespace \
  --set expose.tls.certificate=secret,\
    expose.tls.certificate.secretName=harbor-tls-cert \
  --set expose.tls.key=secret,\
    expose.tls.key.secretName=harbor-tls-key \
  --set harborAdminPassword=Harbor12345 \
  --set database.password=root123 \
  --set redis.password=redis123 \
  --set trivy.enabled=true \
  --set persistence.enabled=true \
  --set persistence.persistentVolumeClaim.size=500Gi
```

### Harbor validation

```bash

# 1. Verify Harbor API

curl -sk https://harbor.internal/api/v2.0/ping

# 2. Login to Harbor

docker login harbor.internal:5000 -u admin -p Harbor12345

# 3. Push a test image

docker pull alpine:3.19
docker tag alpine:3.19 harbor.internal:5000/library/alpine:3.19
docker push harbor.internal:5000/library/alpine:3.19

# 4. Verify image in Harbor UI

curl -sk -u admin:Harbor12345 https://harbor.internal/api/v2.0/projects/library/repositories/alpine/artifacts
```

## Nexus Repository Manager installation

### Option A: Docker Compose (preferred for air-gapped)

```bash

# 1. Create Nexus directory

mkdir -p /opt/nexus/{data,etc,logs}

# 2. Configure Nexus

cat > /opt/nexus/etc/nexus.properties <<'EOF'
application-port=8081
application-host=0.0.0.0
nexus-context-path=/nexus
nexus-scripts-dir=/data/nexus/groovy
nexus-security-keystore=nexus-security.keystore
nexus-security-keystore-password=changeit
nexus-security-truststore=nexus-security-truststore.jks
nexus-security-truststore-password=changeit
runtime=kyarafw
karaf.port=8090
karaf.host=0.0.0.0
EOF

cat > /opt/nexus/etc/org.sonatype.nexus.repository.repository.factories-Repositories.cfg <<'EOF'

# Repository configuration managed by Ansible

EOF

# 3. Docker Compose for Nexus

cat > /opt/nexus/docker-compose.yml <<'EOF'
version: '3.8'

services:
  nexus:
    image: sonatype/nexus3:3.66.0
    container_name: nexus
    restart: unless-stopped
    ports:
      - "8081:8081"
    volumes:
      - /opt/nexus/data:/nexus-data
      - /opt/nexus/etc:/nexus/etc
    environment:
      - NEXUS_CONTEXT=/nexus
    networks:
      - registry-net

networks:
  registry-net:
    driver: bridge
EOF

# 4. Start Nexus

docker-compose -f /opt/nexus/docker-compose.yml up -d

# 5. Wait for Nexus to start (takes 2-5 minutes)

sleep 120

# 6. Get initial admin password

cat /opt/nexus/data/admin.password
```

### Option B: Native RPM installation (RHEL-family)

```bash

# 1. Install Nexus RPM from internal mirror

rpm -ivh https://nexus.internal/repository/raw/sonatype-nexus-3.66.0-02.el7.rpm

# 2. Configure Nexus

mkdir -p /opt/sonatype/sonatype-work
chown -R nexus:nexus /opt/sonatype
chown -R nexus:nexus /opt/nexus

# 3. Edit Nexus properties

sed -i 's/#application-port=8081/application-port=8081/' /opt/nexus/bin/nexus.vmoptions
sed -i 's/-Xms1200M/-Xms2G/' /opt/nexus/bin/nexus.vmoptions
sed -i 's/-Xmx1200M/-Xmx4G/' /opt/nexus/bin/nexus.vmoptions

# 4. Start Nexus

systemctl enable --now nexus

# 5. Wait and get password

cat /opt/nexus/data/admin.password
```

### Nexus validation

```bash

# 1. Verify Nexus API

curl -sk http://nexus.internal:8081/service/rest/v1/status

# 2. Login to Nexus UI

curl -sk -u admin:$(cat /opt/nexus/data/admin.password) \
  https://nexus.internal:8081/service/rest/v1/security/users/admin

# 3. Create a repository (example: hosted Maven)

curl -sk -u admin:admin123 \
  -H "Content-Type: application/json" \
  -d '{"name":"maven-releases","type":"maven2","online":true,"storage":{"blobStoreName":"default","strictContentTypeEncoding":true},"maven":{"versionPolicy":"release","layoutPolicy":"strict"}}' \
  https://nexus.internal:8081/service/rest/v1/repository/maven/hosted
```

## GitLab installation

### Option A: Docker Compose

```bash

# 1. Create GitLab directory

mkdir -p /opt/gitlab/{config,data,logs}

# 2. Configure GitLab

cat > /opt/gitlab/docker-compose.yml <<'EOF'
version: '3.8'

services:
  gitlab:
    image: registry.gitlab.com/gitlab/gitlab-ee:17.0.0
    container_name: gitlab
    hostname: gitlab.internal
    restart: unless-stopped
    environment:
      GITLAB_OMNIBUS_CONFIG: |
        external_url 'https://gitlab.internal'
        gitlab_rails['initial_root_password'] = 'GitLab12345!'
        nginx['redirect_http_to_https'] = true
        nginx['ssl_certificate'] = '/etc/gitlab/ssl/gitlab.internal.crt'
        nginx['ssl_certificate_key'] = '/etc/gitlab/ssl/gitlab.internal.key'
        gitlab_rails['smtp_enable'] = true
        gitlab_rails['smtp_address'] = 'smtp.internal'
        gitlab_rails['smtp_port'] = 25
    volumes:
      - /opt/gitlab/config:/etc/gitlab
      - /opt/gitlab/data:/var/opt/gitlab
      - /opt/gitlab/logs:/var/log/gitlab
    ports:
      - "80:80"
      - "443:443"
      - "22:22"
    networks:
      - registry-net

networks:
  registry-net:
    driver: bridge
EOF

# 3. Start GitLab

docker-compose -f /opt/gitlab/docker-compose.yml up -d

# 4. Wait for GitLab (takes 5-10 minutes on first start)

sleep 300

# 5. Run GitLab reconfigure

docker exec gitlab gitlab-ctl reconfigure
```

### Option B: Native package installation (RHEL-family)

```bash

# 1. Install dependencies

dnf install -y curl openssh-server tzdata perl

# 2. Add GitLab repository

curl https://packages.gitlab.com/install/repositories/gitlab/gitlab-ee/script/rpm.sh | bash

# 3. Install GitLab

dnf install -y gitlab-ee

# 4. Configure GitLab

cat > /etc/gitlab/gitlab.rb <<'EOF'
external_url 'https://gitlab.internal'
gitlab_rails['initial_root_password'] = 'GitLab12345!'
nginx['redirect_http_to_https'] = true
nginx['ssl_certificate'] = '/etc/gitlab/ssl/gitlab.internal.crt'
nginx['ssl_certificate_key'] = '/etc/gitlab/ssl/gitlab.internal.key'
EOF

# 5. Reconfigure and start

gitlab-ctl reconfigure
```

### GitLab validation

```bash

# 1. Verify GitLab health

curl -sk https://gitlab.internal/-/health

# 2. Login as root

curl -sk -X POST -d "user[login]=root&user[password]=GitLab12345!" \
  https://gitlab.internal/users/sign_in

# 3. Create a project

curl -sk -H "PRIVATE-TOKEN: <your_personal_access_token>" \
  -d "name=my-project" \
  https://gitlab.internal/api/v4/projects
```

## Air-gapped installation

### Option 1: Offline installer tarballs (Harbor)

Harbor provides an offline installer that includes all container images as a tarball:

```bash

# On connected staging host:

curl -L https://github.com/goharbor/harbor/releases/download/v2.10.0/harbor-offline-installer-v2.10.0.tgz -o harbor-offline.tgz

# Transfer harbor-offline.tgz to air-gapped environment via physical media

# On air-gapped host:

tar xzf harbor-offline.tgz
cd harbor
./prepare.sh
./install.sh
```

### Option 2: Docker image export/import

```bash

# On connected staging host:

docker pull registry.gitlab.com/gitlab/gitlab-ee:17.0.0
docker save -o gitlab-ee.tar registry.gitlab.com/gitlab-ee:17.0.0

# Transfer gitlab-ee.tar to air-gapped host via physical media

# On air-gapped host:

docker load -i gitlab-ee.tar
docker run -d --name gitlab -p 80:80 -p 443:443 -p 22:22 \
  -v /opt/gitlab/config:/etc/gitlab \
  -v /opt/gitlab/data:/var/opt/gitlab \
  -v /opt/gitlab/logs:/var/log/gitlab \
  registry.gitlab.com/gitlab-ee:17.0.0
```

### Option 3: Helm chart export

```bash

# On connected staging host:

helm pull harbor/harbor --version 2.10.0 --untar
helm pull bitnami/nexus --version 3.66.0 --untar

# Transfer charts to air-gapped host

# On air-gapped host:

helm install harbor ./harbor --namespace harbor --create-namespace
helm install nexus ./nexus --namespace nexus --create-namespace
```

### Option 4: YUM/APT offline repository

For OS packages and native installs, use internal Nexus as a mirror:

```bash

# On air-gapped host, configure YUM to use internal Nexus

cat > /etc/yum.repos.d/internal.repo <<'EOF'
[internal-nexus]
name=Internal Nexus Repository
baseurl=https://nexus.internal:8443/repository/rpm-public/
enabled=1
gpgcheck=0
EOF

dnf install -y gitlab-ee
```
