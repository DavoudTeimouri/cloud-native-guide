# Installation & Configuration

## Purpose and scope
Native and container-based installation (Docker Compose preferred where supported), persistent storage, HA/scalability, backup/restore, auth, TLS, monitoring, logging, upgrades.

## Installation
- Harbor: Helm chart from internal Helm repo, or native install
- Nexus: native install or container, from internal repo
- Both: TLS via internal CA/cert-manager, auth via Keycloak OIDC/local

## Configuration
- Persistent storage for image layers/packages
- HA and scalability
- Backup and restore
- Authentication and authorization (Keycloak OIDC)
- TLS (internal CA)
- Monitoring and logging (Prometheus, Loki)
- Upgrade procedures
