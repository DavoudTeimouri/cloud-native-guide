# 3.7 Validation & Operations

## Purpose and scope
Connectivity testing, synchronization validation, integrity verification, backup, monitoring, troubleshooting, recovery for repositories/registries.

## Validation
- Connectivity: curl/skopeo inspect against internal Harbor/Nexus
- Synchronization validation: verify mirrored artifacts match upstream
- Integrity verification: checksums, Cosign signatures, SBOM
- Backup: Velero, etcd snapshots, RGW snapshots
- Monitoring: Prometheus scrape Harbor/Nexus
- Troubleshooting: common failure conditions and resolution
- Recovery: restore from backup, re-mirror from staging
