# Validation & Operations

## Purpose and scope

Connectivity testing, synchronization validation, integrity verification, backup, monitoring, troubleshooting, and recovery for repositories and registries. This section defines how to verify that the repository/registry infrastructure is operating correctly in both connected and air-gapped environments.

## Connectivity validation

### Verify Harbor is reachable

```bash

# API health check

curl -sk https://harbor.internal/api/v2.0/ping

# Expected: {"ok":true}

# Docker/OCI registry v2 API

curl -sk https://harbor.internal:443/v2/

# Expected: {"name":"distribution","version":"registry/2.0"}

# Docker login test

docker login harbor.internal:443 -u admin -p <password>

# Expected: Login Succeeded

# Image pull through Harbor

docker pull harbor.internal:443/library/alpine:3.19
```

### Verify Nexus is reachable

```bash

# Nexus status API

curl -sk http://nexus.internal:8081/service/rest/v1/status

# Expected: JSON with version info

# Repository list

curl -sk -u admin:<password> \
  https://nexus.internal:8081/service/rest/v1/repositories

# Repository content

curl -sk -u admin:<password> \
  https://nexus.internal:8081/service/rest/v1/search?repository=maven-releases
```

### Verify GitLab is reachable

```bash

# Health endpoint

curl -sk https://gitlab.internal/-/health

# Expected: OK

# API status

curl -sk -H "PRIVATE-TOKEN: <token>" \
  https://gitlab.internal/api/v4/projects
```

## Synchronization validation

### Verify Harbor replication

```bash

# Check replication status

curl -sk -u admin:<password> \
  https://harbor.internal/api/v2.0/replication/jobs

# Trigger manual replication

curl -sk -X POST -u admin:<password> \
  https://harbor.internal/api/v2.0/replication/jobs/<id>/run

# Verify replicated image exists

curl -sk -u admin:<password> \
  https://harbor.internal/api/v2.0/projects/library/repositories/alpine/artifacts
```

### Verify Nexus sync

```bash

# Check proxy repository cache

curl -sk -u admin:<password> \
  https://nexus.internal:8081/service/rest/v1/components?repository=maven-public

# Verify artifact was proxied from upstream

curl -sk -u admin:<password> \
  https://nexus.internal:8443/repository/maven-public/org/apache/maven/plugins/maven-jar-plugin/maven-metadata.xml
```

### Verify GitLab mirror

```bash

# Check mirrored project

curl -sk -H "PRIVATE-TOKEN: <token>" \
  https://gitlab.internal/api/v4/projects?search=upstream-mirror

# Check last sync activity

curl -sk -H "PRIVATE-TOKEN: <token>" \
  https://gitlab.internal/api/v4/projects/<id>/events
```

## Integrity verification

### Verify image integrity (Cosign signatures)

```bash

# Verify signed image

cosign verify harbor.internal:5000/library/alpine:3.19 \
  --key cosign.pub

# Expected: Verified OK

```

### Verify artifact checksums (SBOM)

```bash

# Get SBOM from Harbor

curl -sk -u admin:<password> \
  https://harbor.internal/api/v2.0/projects/library/repositories/alpine/artifacts/3.19/summary

# Verify checksum

sha256sum alpine-3.19.tar.gz

# Compare with SBOM sha256

```

### Verify RPM/DEB package signatures

```bash

# Verify RPM signature

rpm --import /etc/pki/rpm-gpg/RPM-GPG-KEY-internal
rpm -qpi <package>.rpm

# Verify DEB signature

apt-key adv --keyserver keyserver.ubuntu.com --recv-keys <key-id>
apt-get install -y <package>
```

## Backup verification

### Harbor backup verification

```bash

# List Harbor backups

curl -sk -u admin:<password> \
  https://harbor.internal/api/v2.0/systeminfo/backups

# Restore from backup (example)

# Harbor backup/restore via harbor-backup/restore scripts

./backup.sh --target /backup/harbor/2024-01-15
./restore.sh --source /backup/harbor/2024-01-15
```

### Nexus backup verification

```bash

# Nexus uses filesystem backup of blob store + database dump

# Verify backup exists

ls -lh /opt/nexus/backup/

# Verify database dump

pg_restore --list /opt/nexus/backup/nexus-db.dump

# Restore Nexus

java -jar /opt/sonatype/nexus/plugins/nexus-backup-restore-*.jar \
  --restore /opt/nexus/backup/
```

### GitLab backup verification

```bash

# List GitLab backups

ls -lh /var/opt/gitlab/backups/

# Restore GitLab backup

gitlab-ctl stop unicorn sidekiq
gitlab-rake gitlab:backup:restore BACKUP=<timestamp>
gitlab-ctl start
gitlab-rake gitlab:check SANITIZE=true
```

## Monitoring

### Prometheus scrape configuration for Harbor

```yaml

# /etc/prometheus/prometheus.yml

scrape_configs:
  - job_name: 'harbor'
    static_configs:
      - targets: ['harbor.internal:443']
    metrics_path: /api/v2.0/metrics
    scheme: https
    tls_config:
      insecure_skip_verify: true
    basic_auth:
      username: admin
      password: <password>
```

### Key Harbor metrics to alert on

| Metric | Alert threshold | Meaning |
| --- | --- | --- |
| `harbor_registry_info` | value == 0 | Harbor registry down |
| `harbor_project_count` | decreasing | Projects deleted unexpectedly |
| `registry_disk_usage_bytes` | > 80% of capacity | Storage almost full |
| `replication_job_status` | != 1 | Replication job failed |

### Prometheus scrape configuration for Nexus

```yaml
scrape_configs:
  - job_name: 'nexus'
    static_configs:
      - targets: ['nexus.internal:8081']
    metrics_path: /metrics
```

### Key Nexus metrics to alert on

| Metric | Alert threshold | Meaning |
| --- | --- | --- |
| `nexus_repository_info` | value == 0 | Nexus repository down |
| `nexus_storage_used_bytes` | > 85% of capacity | Storage almost full |
| `nexus_api_response_seconds` | > 5 | API slow |

### Grafana dashboards

Create dashboards for:

- Harbor: image pull/push rate, replication lag, storage usage, vulnerability count
- Nexus: component download rate, repository count, storage usage, API latency
- GitLab: pipeline success rate, merge request rate, storage usage, user count

## Troubleshooting

### Common failures and resolutions

| Symptom | Likely cause | Resolution |
| --- | --- | --- |
| `docker login` fails with 401 | Wrong credentials or expired token | Reset password, check Harbor LDAP/OIDC config |
| `docker pull` fails with 404 | Image not in Harbor | Push image to Harbor first, or check repository name |
| `docker pull` fails with 502 | Harbor backend down | Check Harbor pods/containers, restart Harbor |
| `dnf install` fails with 404 | Package not in Nexus | Add package to Nexus hosted repo, or sync from upstream |
| `npm install` fails with 403 | Wrong registry URL or auth | Check npm registry URL, check Nexus token |
| `helm install` fails with 404 | Chart not in Harbor | Push chart to Harbor chart repo first |
| Git `clone` fails with 403 | Wrong GitLab token or no project access | Generate new personal access token, check project membership |
| Replication fails | Network or auth issue between instances | Check firewall, check credentials, check network connectivity |
| Harbor storage full | Image layers consuming disk | Run garbage collection: `harbor garbage-collection` |
| Nexus storage full | Cached artifacts consuming disk | Run Nexus cleanup policies, delete unused snapshots |

### Debug commands

```bash

# Check all registry endpoints

curl -sk https://harbor.internal/api/v2.0/ping
curl -sk http://nexus.internal:8081/service/rest/v1/status
curl -sk https://gitlab.internal/-/health

# Check DNS resolution

nslookup harbor.internal
nslookup nexus.internal
nslookup gitlab.internal

# Check TLS certificates

openssl s_client -connect harbor.internal:443 </dev/null 2>/dev/null | openssl x509 -noout -dates

# Check reverse proxy

curl -sk -I https://harbor.internal:443/
curl -sk -I https://nexus.internal:8443/

# Check container registry API

skopeo inspect docker://harbor.internal:443/library/alpine:3.19
```

## Recovery

### Restore Harbor from backup

```bash

# Stop Harbor

cd /opt/harbor
./down.sh

# Restore database from backup

./restore.sh --source /backup/harbor/2024-01-15

# Start Harbor

./up.sh
```

### Restore Nexus from backup

```bash

# Stop Nexus

systemctl stop nexus

# Restore database

pg_restore -d nexus /opt/nexus/backup/nexus-db.dump

# Restore blob store

cp -r /opt/nexus/backup/sonatype-work/* /opt/sonatype/sonatype-work/

# Start Nexus

systemctl start nexus
```

### Restore GitLab from backup

```bash

# Stop GitLab services

gitlab-ctl stop unicorn sidekiq

# Restore backup

gitlab-rake gitlab:backup:restore BACKUP=<timestamp>

# Start GitLab

gitlab-ctl start

# Verify

gitlab-rake gitlab:check SANITIZE=true
```

## Validation checklist

Before considering a repository/registry production-ready:

- [ ] Harbor API responds at `https://harbor.internal/api/v2.0/ping`
- [ ] Nexus API responds at `http://nexus.internal:8081/service/rest/v1/status`
- [ ] GitLab health responds at `https://gitlab.internal/-/health`
- [ ] Docker pull from Harbor succeeds
- [ ] YUM/DNF install from Nexus succeeds
- [ ] `npm install` from Nexus succeeds
- [ ] `pip install` from Nexus succeeds
- [ ] `git clone` from GitLab via HTTPS succeeds
- [ ] `git clone` from GitLab via SSH succeeds
- [ ] Helm install from Harbor chart repo succeeds
- [ ] Image signature verification (Cosign) passes
- [ ] Package checksum verification (RPM/DEB) passes
- [ ] Backup and restore drill completes successfully
- [ ] Monitoring alerts fire on component failure
- [ ] Air-gapped environment: all clients point to internal mirrors only
- [ ] Air-gapped environment: no public internet access required
