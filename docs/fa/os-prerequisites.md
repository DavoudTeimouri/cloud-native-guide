# پیش‌نیاز‌های سیستم‌عامل

پیش‌نیازهای آماده‌سازی میزبان‌های لینوکس برای پلتفرم کلود-نیتیو استیک.

## سیستم‌عامل‌هایupported

| سیستم‌عامل | نسخه | معماری | کرنل | وضعیت |
|-------------|--------|---------|------|-------|
| Oracle Linux | 9 | x86_64 | 5.14+ | ترجیحی |
| Ubuntu Server | 24.04 LTS | x86_64 | 6.6+ | ترجیحی |
| Ubuntu Server | 22.04 LTS | x86_64 | 5.15+ | پشتیبانی |
| RHEL | 9 | x86_64 | 5.14+ | پشتیبانی |
| Rocky Linux | 9 | x86_64 | 5.14+ | پشتیبانی |
| AlmaLinux | 9 | x86_64 | 5.14+ | پشتیبانی |

## پیش‌نیازهای Node کنترل

- پایتون 3.11-3.13
- ansible-core >=2.19.0, <2.20.0 (بر اساس نیازهای Kubespray v2.32.0)
- دسترسی کلید SSH به همه میزبان‌های هدف
- دسترسی به نکسوس داخلی (`https://nexus.internal`) و هاربور (`https://harbor.internal`)

## پیش‌نیازهای میزبان هدف

- سرور SSH در پورت 22 در حال اجرا
- کاربر `ansible` با sudo بدون رمز عبور
- پایتون 3 نصب شده
- دسترسی شبکه به نکسوس داخلی و هاربور

## پیش‌نیازهای کرنل

برای کربرنتیز >= 1.32:
- کرنل LTS پیشنهادی 4.x: 4.19
- هر کرنل 5.x یا 6.x پشتیبانی می‌شود
- cgroups v2 نیاز به >= 4.15 دارد (5.8+ توصیه می‌شود)

### نیازهای کرنل مخصوص CNI

| CNI | حداقل کرنل |
|-----|------------|
| Cilium 1.20.3 | 5.10 |
| Calico 3.31.7 | 4.19 |

### تأیید

```bash
# بررسی نسخه کرنل
uname -r

# خروجی مورد انتظار: >= 4.19 (حداقل عمومی کربرنتیز)
# Cilium: >= 5.10
# Calico: >= 4.19

# بررسی نسخه cgroups
stat -fc %T /sys/fs/cgroup

# خروجی مورد انتظار: cgroup2fs
```

## پیش‌نیازهای سخت‌افزار

| منبع | حداقل | پیشنهادی |
|--------|-------|----------|
| CPU | 2 هسته | 4+ هسته |
| حافظه | 4 گیگابایت | 8+ گیگابایت |
| دیسک | 50 گیگابایت | 100+ گیگابایت |
| شبکه | 1 گیگابت/ثانیه | 10 گیگابت/ثانیه |

## پیش‌نیازهای شبکه

- آدرس IP استاتیک پیکربندی شده
- حل DNS کار می‌کند
- نکسوس داخلی و هاربور قابل دسترسی هستند
