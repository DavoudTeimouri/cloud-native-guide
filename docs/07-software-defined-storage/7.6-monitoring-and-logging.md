# Monitoring and Logging

## Purpose and scope
Ceph health, cluster performance, OSD health, MON quorum, capacity, latency, IOPS, Prometheus integration, Grafana dashboards, alerting, logs.

## Monitoring
- Ceph: ceph -s, ceph osd stat, ceph osd df, ceph pg stat, ceph health detail.
- Prometheus: ceph_exporter metrics (cluster health, OSD health, PG state, OSD utilization, recovery).
- Grafana: Ceph dashboards (cluster overview, OSD, PG, pool, capacity).
- Alertmanager: alerts for OSD down, MON quorum lost, PG degraded, capacity above threshold.

## Key metrics
- Ceph health (HEALTH_OK/WARN/ERR).
- OSD up/down, in/out.
- PG state (active+clean, degraded, undersized, misplaced).
- Capacity: bytes used/available, utilization %.
- Latency: op latency (read/write), recovery rate.
- IOPS: read/write operations per second.

## Logging
- Ceph logs: /var/log/ceph/ on cephadm hosts; journalctl -u ceph-* on systemd.
- Promtail/Fluent Bit: ship Ceph logs to Loki.
- Audit: access operations via RGW logs.
