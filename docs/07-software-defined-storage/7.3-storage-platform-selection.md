# 7.3 Storage Platform Selection

## Purpose and scope
Compare Ceph, Rook-Ceph, Longhorn, hardware appliances, other SDS solutions.

## Selection matrix
| Platform | Block | File | Object | HA | Complexity | Best for |
|---|---|---|---|---|---|---|
| Ceph (independent) | Yes | Yes | Yes | Yes | High | Large multi-cluster platform |
| Rook-Ceph | Yes | Yes | Yes | Yes | Medium | K8s-native app storage |
| Longhorn | Yes | No | No | Yes | Low | Small/medium K8s |
| Hardware appliance | Yes | Yes | Limited | Yes | Low | Existing SAN, block-only |

## Recommendation
- Use independent Ceph for platform-wide block+file+object
- Use Rook-Ceph for application-cluster persistent storage
- Use Longhorn for lightweight dev/small prod clusters
- Use hardware appliances where block storage already exists
