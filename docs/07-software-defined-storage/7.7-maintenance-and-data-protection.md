# 7.7 Maintenance and Data Protection

## Purpose and scope
Backup, recovery, failure handling, disk replacement, OSD replacement, rebalancing, expansion, migration, disaster recovery for SDS.

## Backup and recovery
- Ceph: RBD snapshots, CephFS snapshots, RGW versioning/object lock; back up to internal object storage or offline media.
- Rook-Ceph: snapshots via CSI VolumeSnapshotClass; back up to internal object storage.
- Hardware appliances: vendor backup/restore procedures; snapshot and replication.
- Test restores regularly; record RTO/RPO.

## Failure handling
- OSD failure: CRUSH rebalances; replace disk, re-add OSD.
- MON failure: quorum preserved with 3+ MONs; recover or replace MON.
- MGR failure: standby MGR takes over; replace failed MGR.
- Network partition: monitor split-brain; verify quorum before writes.

## Disk replacement
- Mark OSD out, wait for rebalance, replace disk, mark OSD in, wait for rebalance complete.
- Verify PG state active+clean before next operation.

## OSD replacement
- ceph osd destroy, ceph osd rm, zap disk, add new OSD, wait for backfill.

## Rebalancing
- Control backfill rate (osd_max_backfills, osd_recovery_sleep) to avoid foreground impact.
- Monitor PG state during rebalance.

## Expansion
- Add OSDs/nodes; update CRUSH map; verify capacity and performance.
- Add pools; adjust replication/erasure coding profiles.

## Migration between storage backends
- Add new StorageClass; migrate PVCs; update applications; verify data integrity; delete old.
