# 7.1 Architecture

## Purpose and scope
Block storage, file storage, object storage, distributed storage, storage networking, data replication, failure domains, capacity planning.

## SDS architectures
| Architecture | Description | When to use |
|---|---|---|
| Independent Ceph | Standalone Ceph cluster, consumed via CSI/RBD/CephFS/RGW | Large scale, block+file+object, multi-cluster |
| Rook-Ceph | Ceph managed by Kubernetes operator | K8s-native, app-cluster storage |
| Longhorn | Lightweight distributed block storage | Small/medium, simple ops |
| Hardware appliances | External storage array via CSI/Fibre/iSCSI | Block-only, existing SAN investment |

## Failure domains
- Rack, host, node, OSD, PG
- CRUSH rules distribute replicas across failure domains
- Minimum 3 MON, 3 MGR, 3+ OSD for HA
