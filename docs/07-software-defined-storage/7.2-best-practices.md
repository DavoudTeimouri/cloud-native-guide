# Best Practices

## Purpose and scope
Production best practices for SDS: monitoring, capacity, failure handling, performance tuning.

## Best practices
- Minimum 3 MON nodes; odd number
- OSD: one per disk, NVMe for DB/WAL, HDD for data
- CRUSH rule: replicated across racks/hosts
- PG count: ~100-300 per OSD
- Monitor OSD health, PG state, capacity
- Alert on: OSD down, PG not active+clean, capacity > 85%
- Backup Ceph config and keys (mon, client.admin, bootstrap-*)
- Test disk replacement and rebalancing quarterly

## Capacity planning
- Reserve 20-30% headroom for rebalancing
- Account for replication factor (3x default) or erasure coding overhead
- Plan OSD expansion before hitting 85% full
