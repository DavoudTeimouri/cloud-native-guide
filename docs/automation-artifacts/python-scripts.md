# Python Script Artifacts

## Purpose and scope

Python scripts for validation, offline staging, and site building. All scripts live under `automation/python/` and `automation/offline-staging/scripts/`. They use only the Python standard library (no external dependencies) so they run in air-gapped control nodes.

## Directory layout

```text
automation/python/
├── check_links.py        # Broken link and dead anchor detector
├── validate_catalog.py   # Catalog/version-matrix validator
├── build_site.py         # Site data.json generator
└── compile.py            # Python syntax checker for scripts

automation/offline-staging/scripts/
├── stage_artifacts.py    # Stage artifacts on connected host
├── import_artifacts.py   # Import artifacts on air-gapped side
├── validate_manifest.py  # Validate offline manifest JSON
├── check_readiness.py    # Check offline staging readiness
└── test_offline_staging.py# Self-checks for offline staging
```

## Customization points

### check_links.py

Run from repo root. No configuration file — reads `docs/` tree directly.

```bash
python3 scripts/check_links.py
```

Customize by editing the script's `IGNORE_PATTERNS` list if you need to skip specific directories.

### validate_catalog.py

Validates `catalog/catalog.json` against `site/data.json` (regenerated by `build_site.py`).

```bash
python3 scripts/build_site.py      # regenerates site/data.json
python3 scripts/validate_catalog.py
```

Customize the catalog in `catalog/catalog.json` — add new `pN` entries for new docs pages.

### build_site.py

Generates `site/data.json` from docs + catalog.

```bash
python3 scripts/build_site.py
```

### Offline staging scripts (air-gapped)

**Connected host (stage):**

```bash
python3 automation/offline-staging/scripts/stage_artifacts.py \
  --manifest manifest.json \
  --output /mnt/offline-media/
```

**Air-gapped host (import):**

```bash
python3 automation/offline-staging/scripts/import_artifacts.py \
  --media /mnt/offline-media/ \
  --target /opt/offline-mirror/
```

**Validate manifest:**

```bash
python3 automation/offline-staging/scripts/validate_manifest.py \
  --manifest manifest.json \
  --schema automation/offline-staging/schema/manifest-schema-v1.json
```

**Check readiness:**

```bash
python3 automation/offline-staging/scripts/check_readiness.py \
  --profile production
```

## Manifest customization

The offline manifest (`manifest.json`) lists components, versions, and source URLs. Edit it to match your pinned versions from `compatibility/version-matrix.md`. See `manifest-schema-v1.json` for the required fields.
