# 2.11 GitLab Server

## Purpose and scope
GitLab infrastructure requirements: OS prep, storage, networking, security, backup, dependencies.

## Requirements
- OS: Oracle Linux 9 or Ubuntu 24.04
- Disk: large disk for repositories, LFS, container registry data
- Network: internal, reachable by Argo CD and CI runners
- PostgreSQL, Redis, object storage
- Secrets file (required to restore)

## Security
- TLS via internal CA/cert-manager
- Secret file backed up separately
- Access via Keycloak OIDC or local (break-glass)

## Backup
- gitlab-backup create; copy tar to object storage
- Repositories, LFS, registry data, config, encryption keys/secrets file
