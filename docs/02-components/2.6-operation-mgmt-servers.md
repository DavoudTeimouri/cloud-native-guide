# 2.6 Operation & Management Servers

## Purpose and scope
Design the operational management environment: pair of Linux management/automation servers plus a Windows management server for GUI tasks. Centralized administration, Ansible, Kubespray, SSH, PowerShell, Git, CLI tools, cert/secret mgmt, admin access, audit logging, backup of operational config, monitoring.

## Architecture
- Two Linux management/automation servers (HA pair) — perform all infra deployment/config
- One Windows management server — GUI-based operational activities
- All infra changes flow through these servers (controlled workflows)

## Tools
- Ansible, Kubespray dependencies, K8s CLI tools, Helm, Git, container tools, SSH, PowerShell, infra utilities, monitoring/troubleshooting tools
- Installed through centralized repository/registry infrastructure (03)

## Configuration management
- Certificate management via Vault PKI / cert-manager
- Secret management via Vault
- Administrative access via Keycloak OIDC (no shared accounts)
- Audit logging of all admin actions
- Backup of operational configuration to Git
