# 2.5 OS Preparation by Role

## Purpose and scope
Role-specific OS preparation procedures: general Linux server, K8s control-plane, K8s worker, storage, load balancer, registry manager, GitLab, automation, monitoring nodes. Do not apply identical configurations to every role.

## Common baseline (all roles)
- OS from internal mirror, containerd prerequisites, Python 3
- Admin user, SSH port/password policy, sudo, timezone/locale, NTP/DNS
- Kernel args, swap off, THP never, max pods, file descriptors
- SELinux/AppArmor, firewall backend, audit retention, unattended updates, CA bundle
- Local accounts only; never joined to directory (ADR-0015)
- Break-glass local account

## Role-specific
- Control plane: etcd disk (local NVMe), max pods, reserved CPU/memory
- Worker: container runtime, kubelet, node labels/taints
- Storage: Ceph OSD disk tuning, filesystem (XFS ftype=1)
- Load balancer: keepalived, HAProxy/Nginx, IP forwarding
- Registry manager: large disk for image layers, backup
- GitLab: PostgreSQL, Redis, object storage
- Automation: Ansible venv, collections from internal mirror
- Monitoring: node_exporter, Fluent Bit, Prometheus scrape targets
