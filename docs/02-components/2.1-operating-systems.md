# Operating Systems

## Purpose and scope
Cover supported operating systems: Oracle Linux, RHEL, Rocky Linux, AlmaLinux, Ubuntu Server, Debian, SUSE Linux Enterprise Server, Windows Server. For each: support status, install, offline, hardening, network, DNS/NTP, storage, firewall, packages, services, kernel, updates, automation.

## Supported OS matrix
| OS | Version | Kernel | Status | Roles |
|---|---|---|---|---|
| Oracle Linux | 9 | 5.14 UEK/RHCK | Preferred | all |
| Ubuntu Server | 24.04 LTS | 6.8+ GA | Preferred | all |
| RHEL/Rocky/Alma | 9 | 5.14 | Supported | all |
| Ubuntu Server | 22.04 LTS | 5.15 | Supported | all |
| Windows Server | 2022 | — | Supported | mgmt GUI only |

OL8 and Ubuntu 20.04 are below Kubespray's 4.19 minimum — not supported.

## Per-OS notes
- SELinux (OL/RHEL/Rocky/Alma): enforcing, do not disable
- AppArmor (Ubuntu): enabled
- Kernel modules: overlay, br_netfilter, ip_vs, nf_conntrack
- sysctl: net.ipv4.ip_forward=1, net.bridge.bridge-nf-call-iptables=1
- Swap: off; transparent huge pages: never
