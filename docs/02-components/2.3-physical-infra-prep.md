# Physical Infrastructure Preparation

## Purpose and scope
Server hardware preparation: CPU/memory, BIOS/UEFI, firmware, RAID/HBA, disk controller, NIC, multipathing, BMC/remote mgmt, compatibility, Secure Boot, NUMA, power, monitoring.

## Hardware requirements
- CPU: dedicated vCPUs for etcd, never shared
- Memory: ECC, sized for workload + OS overhead
- Disk: local SSD/NVMe for etcd, Ceph OSD DB/WAL; never shared virtual disk for Ceph OSD
- NIC: redundant, redundant paths for storage network
- BMC/IPMI: out-of-band management

## BIOS/UEFI
- Secure Boot: enabled where supported
- Virtualization: enabled (VT-x/AMD-V)
- SR-IOV: enabled for GPU passthrough/NIC
- Power policy: performance

## Firmware
- Lifecycle management via BMC/vendor tools
- Keep firmware current; document versions
