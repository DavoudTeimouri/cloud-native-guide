# 2.7 Kubernetes Nodes

## Purpose and scope
Node preparation for control-plane nodes, worker nodes, infrastructure workers, GPU workers, specialized application workers.

## Control-plane node
- OS baseline + containerd
- etcd data dir on local NVMe
- kube-apiserver/scheduler/controller-manager via Kubespray
- Reserved CPU/memory for system components

## Worker node
- OS baseline + containerd
- kubelet, CNI (Cilium), kube-proxy (replaced by Cilium)
- Node labels/taints for workload placement

## Infrastructure worker
- Runs management services (Rancher, Argo CD, monitoring)
- Tainted for infra workloads only

## GPU worker
- NVIDIA H100/H200, driver + CUDA
- MIG for production multi-tenancy; time-slicing for dev
- Node Feature Discovery, GPU Operator

## Specialized worker
- Storage-facing: Ceph OSD/Rook
- Tuned for workload (storage/network/Gpu)
