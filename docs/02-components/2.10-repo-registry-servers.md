# Repository & Registry Manager Servers

## Purpose and scope
Prepare infrastructure for Nexus Repository, Harbor, and other artifact repositories/container registries. Native and container-based deployment requirements.

## Requirements
- Harbor: images/OCI charts, large disk, internal CA, TLS
- Nexus: RPM/DEB/APT/Maven packages, PostgreSQL, object storage
- Both: air-gapped mirroring, backup, monitoring

## Deployment
- Harbor: Helm chart or native, from internal Helm repo
- Nexus: native install or container, from internal repo
