# Virtualization Platform Preparation

## Purpose and scope

Prepare VMware vSphere/ESXi, KVM/Proxmox VE, and other hypervisors: install, networking, distributed switching, storage integration, HA, VM sizing, reservations, anti-affinity, passthrough, backup.

## Hypervisors

- VMware vSphere/ESXi: enterprise, mature, vMotion/DRS
- KVM/Proxmox VE: open source, libvirt/QEMU

## Configuration

- Distributed switching for VM networking
- Storage integration: shared storage for vMotion, local for Ceph OSD
- HA and resource scheduling (HA/DRS)
- VM sizing: right-size vCPU/RAM/disk per role
- CPU/memory reservations for control plane and etcd
- VM placement and anti-affinity: spread control plane across hosts
- Passthrough: GPU whole card, NIC SR-IOV
- Backup and recovery: VM-level backup, snapshots

## Kubernetes virtualization considerations

- Nested virtualization not recommended for production K8s
- Ensure VMs have adequate resources; do not overcommit control plane

## Automation: Terraform VM provisioning

Provision VMs on vSphere/KVM/Proxmox via Terraform:

```bash
# Initialize
cd automation/terraform
terraform init

# Copy and customize variables
cp terraform.tfvars.example terraform.tfvars
# Edit terraform.tfvars: vm_flavor, vm_network, node_count, internal_registry, vault_addr

# Dry-run
terraform plan -var-file=terraform.tfvars

# Apply
terraform apply -var-file=terraform.tfvars -auto-approve

# Capture outputs for Ansible inventory
terraform output new_node_ips
# Add the IPs to automation/ansible/inventories/production/hosts.ini under the right group
```

**Customization variables** (`automation/terraform/terraform.tfvars`):

| Variable | Default | Customize when |
| --- | --- | --- |
| `vm_username` | `ansible` | Your SSH admin user differs |
| `vm_os_image` | `oracle-linux-9` | Use Ubuntu/RHEL/Windows image |
| `vm_flavor` | `m4.large` | Right-size for your role |
| `vm_network` | `internal` | Your network name differs |
| `target_cluster` | `application` | `management`, `storage`, `load-balancers` |
| `node_count` | `1` | Number of VMs to provision |
| `internal_registry` | `harbor.internal:5000` | Your Harbor address differs |
| `vault_addr` | `https://vault.internal:8200` | Your Vault address differs |

**Provider examples** (`automation/terraform/virtualization.md`):

| Platform | Provider | Notes |
| --- | --- | --- |
| VMware vSphere | `hashicorp/vsphere` | Primary platform; template clone + customization spec |
| libvirt/KVM | `dmacvicar/libvirt` | Local lab and CI runners |
| Proxmox | `bpg/proxmox` | Alternative on-prem hypervisor |
| oVirt/RHEV | `terraform-provider-ovirt` | RHEV-based virtualization |
| OpenStack | `terraform-provider-openstack` | Private cloud with Nova |

**Layer separation** — Terraform owns VMs/networks/disks; Ansible (`automation/ansible/playbooks/os-prep-base.yml`) owns OS config after boot.
