# Ceph & Storage Nodes

## Purpose and scope
Prepare Ceph MON, MGR, OSD, MDS, RGW and other storage roles. Disk, network, CPU, memory, failure-domain considerations.

## Roles
- MON: small disk, odd count (3+), low CPU
- MGR: management, dashboards
- OSD: data disks (SSD/NVMe), DB/WAL on separate NVMe
- MDS: CephFS metadata
- RGW: object storage, network bandwidth

## Disk
- XFS ftype=1 for overlay2
- noatime on data filesystems
- Separate journal from data device on Ceph
- fio baseline before storage changes

## Network
- Ceph public + cluster networks (separate)
- 10 GbE+ recommended for OSD replication
