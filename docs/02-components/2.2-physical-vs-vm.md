# 2.2 Physical vs Virtual Machines

## Purpose and scope
Select between bare-metal servers, virtual machines, and hybrid deployments. Advantages, disadvantages, operational implications, performance, failure-domain implications.

## Comparison
| Factor | Bare metal | Virtual machines | Hybrid |
|---|---|---|---|
| Performance | Best (no hypervisor) | Good (small overhead) | Mixed |
| IO latency | Predictable (local disk) | Shared (virtual disk) | Mixed |
| Failure domain | Hardware | Hypervisor + hardware | Both |
| GPU | Full card passthrough | Limited (passthrough complex) | Mixed |
| Ceph OSD | Raw disk preferred | Raw/SCSI passthrough, never shared vdisk | Mixed |
| Provisioning | PXE/IPMI/BMC | Template/clone/cloud-init | Both |

## Guidance
- Ceph OSDs: never on shared virtual disk; use raw or SCSI-passthrough.
- etcd: local SSD, dedicated vCPUs, never on shared storage.
- GPU: pass whole card (MIG not virtualizable).
- Hypervisor joins failure domain — include in DR plan.
