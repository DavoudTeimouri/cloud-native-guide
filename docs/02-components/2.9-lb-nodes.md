# Load Balancer Nodes

## Purpose and scope
OS preparation, network configuration, VIP support, HA requirements, operational hardening for load balancer nodes.

## Preparation
- OS baseline + containerd (if container-based LB)
- Keepalived for VIP/failover (unicast peers)
- HAProxy (L4) and Nginx (L7) on host network via Docker Compose
- IP forwarding enabled
- Firewall: only LB ports open

## VIP support
- Active/Active: two VIPs balanced by router ECMP/BGP
- Active/Standby: single VRRP VIP (not recommended for production edge)
- Tier 2: MetalLB pool in-cluster; Tier 3: DNS/GSLB
