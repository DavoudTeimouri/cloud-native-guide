# Other Infrastructure Components

## Purpose and scope
Identify additional required infrastructure: DNS, NTP, PKI/CAs, LDAP/Active Directory, Vault/secret managers, SMTP, backup infrastructure, security scanning, vulnerability management, operational services.

## Components
- DNS: CoreDNS with forwarders, internal *.internal zone
- NTP: chrony, clock skew < 100 ms
- PKI/CA: internal CA rooted in Vault PKI, cert-manager issues/renews
- LDAP/AD: Keycloak as broker, no host AD join
- Vault: secrets, PKI, encryption at rest/transit
- SMTP: internal smarthost for alerting (air-gapped)
- Backup infrastructure: Velero, Ceph RGW, offline media
- Security scanning: Trivy, Falco, image signing (Cosign), SBOM
- Vulnerability management: monthly DB refresh, mirrored offline
