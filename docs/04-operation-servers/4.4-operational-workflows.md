# 4.4 Operational Workflows

## Purpose and scope
Complete workflows: OS preparation, infrastructure configuration, Kubernetes deployment, storage deployment, load balancer configuration, repository synchronization, monitoring configuration, troubleshooting, maintenance, upgrade operations.

## Workflows
- OS preparation: internal mirror → baseline → join cluster
- Infrastructure config: Ansible playbooks, idempotent
- Kubernetes deployment: Kubespray, one control-plane node at a time
- Storage deployment: Ceph cephadm or Rook-Ceph
- Load balancer config: Keepalived, HAProxy, Nginx, MetalLB
- Repository synchronization: mirror from upstream to internal
- Monitoring configuration: Prometheus targets, Grafana dashboards, Alertmanager rules
- Troubleshooting: symptom-driven runbooks
- Maintenance: patching, cert renewal, backup verification
- Upgrade operations: version compatibility, backup, pre/post validation, rollback
