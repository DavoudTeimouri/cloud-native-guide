# 4.2 Required Tools

## Purpose and scope
Install and configure all necessary tools through centralized repository/registry infrastructure: Ansible, Kubespray dependencies, K8s CLI tools, Helm, Git, container tools, SSH, PowerShell, infrastructure utilities, monitoring/troubleshooting tools.

## Tools
- Ansible: venv 3.11–3.13, ansible-core 2.19.x, collections from internal mirror
- Kubespray: release-2.32 checkout
- K8s CLI: kubectl
- Helm: 3.22.0
- Git: version control
- Container tools: Docker/containerd, skopeo, crictl
- SSH, PowerShell, infrastructure utilities
- Monitoring/troubleshooting tools: node_exporter, Fluent Bit, etc.

## Installation
All tools installed from internal repositories (DNF/APT, internal PyPI, internal Helm chart repo, internal GitLab).
