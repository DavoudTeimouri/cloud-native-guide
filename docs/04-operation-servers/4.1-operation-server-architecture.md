# Operation Server Architecture

## Purpose and scope
Operational architecture and responsibilities of Linux and Windows management servers. Pair of Linux management/automation servers plus Windows management server for GUI tasks.

## Architecture
- Two Linux management/automation servers (HA pair) — perform all infra deployment/config
- One Windows management server — GUI-based operational activities
- All infra changes flow through these servers (controlled workflows)

## Responsibilities
- Centralized administration
- Ansible, Kubespray, SSH, PowerShell, Git, CLI tools
- Certificate management (Vault PKI/cert-manager)
- Secret management (Vault)
- Administrative access (Keycloak OIDC)
- Audit logging
- Backup of operational configuration
- Monitoring and management tools
