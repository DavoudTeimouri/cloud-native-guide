# 4.3 Centralized Network Access Matrix

## Purpose and scope
Consolidated matrix describing network access required by management servers to operate the entire infrastructure. All administrative access follows least-privilege principles.

## Matrix
- Management servers → internal Harbor/Nexus/GitLab (artifact access)
- Management servers → target nodes (SSH port 22, Ansible)
- Management servers → Keycloak/Vault (OIDC/secrets)
- Management servers → Kubernetes API (kubectl)
- Management servers → monitoring targets (Prometheus scrape)
