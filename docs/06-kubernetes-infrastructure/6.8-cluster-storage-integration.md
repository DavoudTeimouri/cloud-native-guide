# Cluster Storage Integration

## Purpose and scope
Evaluate and document Rook-Ceph, Longhorn, external Ceph, hardware storage appliances, and other CSI-compatible solutions. Include deployment on management and application clusters where applicable.

## Storage options
| Solution | Best for | Management cluster | Application cluster |
|---|---|---|---|
| Rook-Ceph | K8s-native block/file/object | Yes | Yes |
| External Ceph (cephadm) | Large-scale block/file/object | No (dedicated hosts) | Yes (via CSI) |
| Longhorn | Simple K8s storage | No | Yes |
| Hardware appliance | Enterprise block/file/SAN | No | Yes (via CSI) |

## Independent vs K8s-managed
- Independent Ceph (cephadm dedicated hosts): preferred for large scale; dedicated hosts per role (MON/MGR/OSD/MDS/RGW).
- K8s-managed (Rook-Ceph): simpler, for smaller scale; runs as pods on application clusters.

## CSI
- Ceph CSI driver for RBD and CephFS.
- StorageClasses per workload (replication, erasure coding).
- Snapshots and expansion supported.
