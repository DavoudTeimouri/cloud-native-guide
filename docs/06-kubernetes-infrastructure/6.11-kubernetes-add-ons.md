# 6.11 Kubernetes Add-ons

## Purpose and scope
Install, configure, integrate, and lifecycle-manage add-ons: MetalLB, Gatekeeper, Falco, Metrics Server, cert-manager, External DNS, ingress controllers, Node Feature Discovery, GPU operators. Identify management-cluster-only, application-cluster-only, and both-cluster deployments.

## Add-on matrix
| Add-on | Mgmt cluster | App cluster | Purpose |
|---|---|---|---|
| MetalLB | — | Yes | In-cluster LoadBalancer IPs |
| Gatekeeper | Yes | Yes | Policy enforcement (OPA) |
| Falco | Yes | Yes | Runtime threat detection |
| F5 NIC / Gateway Fabric | Yes | Yes | L7 ingress + Gateway API |
| cert-manager | Yes | Yes | Workload certificates |
| External DNS | — | Yes | DNS for services/ingress |
| Metrics Server | Yes | Yes | HPA/ VPA metrics |
| Node Feature Discovery | — | Yes | Node feature labels (GPU, etc.) |
| GPU Operator | — | Yes | GPU workload management |

## Installation
- Install via Helm from internal Helm repository (air-gapped).
- Values files stored in Git; never download charts at runtime (missing chart reported, never downloaded).
- cert-manager: Vault PKI or bootstrap issuer.
- External DNS: RFC2136 or CoreDNS etcd backend.

## Lifecycle
- Upgrade via Argo CD ApplicationSet (GitOps).
- Pin versions in shared version & compatibility matrix.
- Missing chart reported, never downloaded silently.
