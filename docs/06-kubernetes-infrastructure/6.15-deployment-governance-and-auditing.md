# Deployment Governance and Auditing

## Purpose and scope
Policies, priorities, tools, workflows for auditing Kubernetes deployments and infrastructure configurations: admission policies, Gatekeeper, policy-as-code, security scanning, configuration auditing, compliance, deployment standards, audit logging, drift detection, deployment approval workflows.

## Policies
- K8s resources: Pod Security Standards (Restricted), resource limits.
- Deployments: Argo CD GitOps, image scanning (Trivy).
- Security configs: network policies, secrets via Vault.
- Resource limits: requests/limits per workload.
- Pod placement: node selectors, taints, topology spread.
- Network policies: default deny, explicit allow.
- Container images: scanned (Trivy), signed (Cosign), SBOM.
- RBAC: least privilege, per-app service accounts.
- Compliance: audit logging, config drift detection.
- Config drift: nightly drift job; reported not silently fixed.

## Gatekeeper
- Single policy engine.
- OPA policies (ReGo).
- Enforcement levels and exception management.

## Deployment approval workflows
- Argo CD ApplicationSet for multi-cluster.
- Image Updater for promotion (dev → staging → prod).
- Destructive actions require explicit confirmation.
