# Application Cluster Deployment

## Purpose and scope
Deploy application clusters: AD-integrated, non-AD, independent clusters, different sizing profiles, dedicated infra and workloads, multi-cluster connectivity.

## Prerequisites
- Management cluster already running (Rancher/Argo CD)
- Load balancer per application cluster (API 6443, ingress 80/443)
- Internal registry reachable
- OS prepared on all nodes

## Deployment steps
1. Prepare OS on control plane and worker nodes
2. Write inventory (kube_control_plane, etcd, kube_node, k8s_cluster)
3. Run Kubespray: `ansible-playbook -i inventory/<cluster>/hosts.yaml cluster.yml`
4. Register cluster to Rancher / Argo CD
5. Deploy CNI, CSI, ingress, monitoring add-ons

## Sizing profiles
| Profile | Control plane | Workers | Use case |
|---|---|---|---|
| Small | 3 | 3 | Dev, small team |
| Medium | 3 | 6-10 | Production team |
| Large | 5 | 10+ | Multi-tenant platform |

## Multi-cluster connectivity
- Cluster registration to Rancher
- Argo CD cluster secret
- Cross-cluster networking via LB or service mesh (optional)

## Validation
- Nodes Ready; system pods Running
- Cluster registered in Rancher/Argo CD
- Workloads schedulable
