# Monitoring and Logging

## Purpose and scope
Prometheus, Grafana, VictoriaMetrics, Alertmanager, Loki, other logging platforms. Management cluster monitoring, application cluster monitoring, centralized monitoring, remote write and federation, long-term metrics storage, log aggregation, dashboards, load balancer integration, offline dependencies.

## Stack
- Prometheus: metrics, recording rules, alerts.
- Grafana: dashboards.
- Alertmanager: alert routing, silencing, inhibition.
- VictoriaMetrics: long-term metrics storage (optional).
- Loki/Fluent Bit: log aggregation.
- Exporters: node_exporter, kube-state-metrics, Ceph exporters.

## Management cluster monitoring
- Monitor Rancher, Argo CD, Keycloak, Vault, Prometheus itself.
- Exposed via management cluster load balancers.

## Application cluster monitoring
- Monitor workloads, nodes, CNI, storage, ingress.
- Scrape via Prometheus; remote write to VictoriaMetrics for long-term.

## Retention, scalability, HA
- Prometheus: local retention, remote write for long-term.
- HA: Prometheus HA, Alertmanager HA.
- Storage sizing based on cardinality and retention.
- Disconnected: all images/mirrors internal; no public dependency.
