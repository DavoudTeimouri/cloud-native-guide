# Kubernetes Networking

## Purpose and scope
CNI selection, Calico, other CNI alternatives, Pod CIDR, Service CIDR, IP pools, IP allocation, VXLAN and IPIP, BGP, MTU, network policies, ingress, egress, DNS, network troubleshooting.

## CNI selection
- Cilium: primary CNI, kube-proxy replacement (strict mode), Hubble, eBPF-based, VXLAN tunneling.
- Calico: alternative (documented, not adopted as primary).

## IP pools
- Pod CIDR: 10.30.0.0/16 per cluster.
- Service CIDR: 10.32.0.0/16 per cluster.
- No overlap between clusters; one address plan per site in Git.

## Networking
- Overlay: VXLAN (Cilium default, UDP 8472).
- Underlay: native routing option (physical MTU).
- MTU: physical MTU − 50 (VXLAN), physical MTU (native).
- BGP: optional for ECMP/BGP VIP balancing at Tier 2 edge.
- NAT: not required for pod-to-service within cluster; egress via external LB.

## Network policies
- Default deny all traffic; explicit allow only.
- CiliumNetworkPolicy for pod-to-pod and pod-to-external.
- DNS egress allowed (port 53 TCP/UDP to kube-dns).
