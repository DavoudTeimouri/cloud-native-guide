# Nexus + Harbor + Stable Endpoint Layer Monitoring

## Monitoring Spec Table

| Aspect | Details |
|---|---|
| **Health** | Repository availability and API response; artifact push/pull success; JVM heap and GC health; storage capacity and blob usage; proxy cache hit/miss; upstream sync status; authentication and authorization errors; TLS certificate validity; HAProxy/Nginx backend health; Keepalived failover status; TLS handshake success/failure |
| **Metrics** | `harbor_image_pull_attempt_total`, `harbor_image_pull_success_total`, `harbor_image_pull_failure_total`, `harbor_image_push_attempt_total`, `harbor_image_push_success_total`, `harbor_image_push_failure_total`, `harbor_image_pull_duration_seconds_bucket`, `harbor_image_push_duration_seconds_bucket`, `harbor_repository_total_size_bytes`, `harbor_blob_total_count`, `harbor_proxy_cache_hit_total`, `harbor_proxy_cache_miss_total`, `harbor_upstream_sync_duration_seconds_bucket`, `harbor_upstream_sync_failure_total`, `harbor_authz_attempt_total{result="denied"}`, `harbor_authz_attempt_total{result="allowed"}`, `proxy_upstream_requests_total{status="5xx"}`, `proxy_upstream_requests_total{status="4xx"}`, `proxy_cache_status`, `haproxy_frontend_connections_total`, `haproxy_backend_connection_failed_total`, `haproxy_ssl_handshake_failure_total`, `tls_certificate_expiry_days` (custom exporter), `keepalived_vrrp_state`, `keepalived_backend_status` |
| **Collection** | `Harbor` exporter Prometheus metrics endpoint (`/metrics`); Harbor internal APIs (`/api/v2.0/health`, `/api/v2.0/projects`, `/api/v2.0/repositories`); Harbor PostgreSQL metrics; Harbor Redis metrics; Nexus metrics endpoint (`/service/rest/v1/status`); HAProxy stats endpoint (`/stats?raw`) or Prometheus exporter; Nginx stub_status; Keepalived VRRP advertisement; Cert exporter (`x509_certificate_expiry`) for certificate validity |
| **Dashboards** | Repository health and API latency; image pull/push success and duration rates; proxy cache hit vs miss rates; upstream sync duration and failure count; authz allowed/denied rates; JVM heap usage and GC pause time; storage capacity and blob count growth; TLS certificate expiry timeline; HAProxy connection saturation and backend health; Keepalived failover latency and state; error rate trends (4xx/5xx) |
| **Alerts** | `RegistryPullFailed` (harbor_image_pull_attempt_total{result="failed"} > 0 for 5m), `RegistryPushFailed` (harbor_image_push_attempt_total{result="failed"} > 0 for 5m), `HighLatencyPull` (harbor_image_pull_duration_seconds_bucket{pct="95"} > 30 for 5m), `HighLatencyPush` (harbor_image_push_duration_seconds_bucket{pct="95"} > 60 for 5m), `ProxyCacheMissSurge` (harbor_proxy_cache_miss_total increase rate > threshold), `UpstreamSyncFailure` (harbor_upstream_sync_failure_total > 0), `AuthzError` (harbor_authz_attempt_total{result="denied"} > 0), `StorageNearFull` (harbor_repository_total_size_bytes / harbor_blob_total_count > 90% of capacity), `TLSExpiringSoon` (tls_certificate_expiry_days < 30), `HAProxyBackendDown` (haproxy_backend_connection_failed_total increase), `KeepalivedFailover` (keepalived_vrrp_state change or keepalived_backend_status == "down") |
| **SLI/SLO** | Image pull success SLO: 99.9% over 30d (harbor_image_pull_success_total / harbor_image_pull_attempt_total); Image pull latency p95 SLO: < 30s over 30d; Image push success SLO: 99.9% over 30d; Proxy cache hit SLO: > 80% over 30d; Upstream sync success SLO: 100% syncs complete without failure over 30d; Authz success SLO: > 99.9% over 30d; Storage capacity SLO: < 90% used over 30d; TLS expiry SLO: 0 certificates expiring within 7d |
| **Tuning** | Harbor proxy cache TTL and invalidation configuration; upstream sync interval and retry backoff; Harbor JVM heap size and GC pause threshold; Nexus storage quotas and cleanup policies; HAProxy connection pool and timeout settings; Keepalived advertisement interval and priority tuning; TLS certificate auto-renewal window |
| **Troubleshooting** | `harborctl status`; `kubectl -n harbor get pods`; `harborctl registry health`; `docker login <harbor>` manually; `curl <harbor>/api/v2.0/health`; `harborctl service restart`; `psql -d harbor -c "SELECT * FROM metrics;"`; `redis-cli -n 0 INFO`; `haproxy -c /etc/haproxy/haproxy.cfg`; `keepalvd` status; `openssl s_client -connect <harbor>:443`; `journalctl -u harbor-tomcat` |
| **Recovery** | Restart Harbor core/services: `harborctl service restart` or `kubectl rollout restart deployment/harbor-core -n harbor`; regenerate and update TLS certificates if expired; clear proxy cache if stale; fix upstream sync configuration and retry; increase Harbor storage (PVC expansion); restart Nexus service or rebuild index if corrupted; re-issue auth secrets if compromised; failover to secondary HAProxy/Keepalived if primary fails |
| **Dependencies** | Harbor core and registry pods running in harbor namespace; Harbor PostgreSQL reachable and healthy; Harbor Redis reachable and healthy; external storage (NFS/S3) available for blobs; HAProxy or Nginx reverse proxy running and healthy; Keepalived cluster for HA if deployed; valid TLS certificates for HTTPS endpoints; network connectivity to registry on port 443 |

## Validation Commands (independent of Prometheus)

| Check | Command | Expected Output |
|---|---|---|
| Harbor health API | `curl -k https://<harbor-host>/api/v2.0/health` | `200` with `status: "healthy"`; all services green |
| Image pull test | `docker pull <harbor>/<project>/<image>:<tag>` | Pull succeeds; `harbor_image_pull_success_total` increments |
| Image push test | `docker tag <image> <harbor>/<project>/<image>:<tag>` && `docker push <harbor>/<project>/<image>:<tag>` | Push succeeds; `harbor_image_push_success_total` increments |
| Proxy cache status | `curl -I <harbor>/v2/` | Headers include `X-Cache: HIT` or `X-Cache: MISS`; `harbor_proxy_cache_hit_total` / `miss_total` increments |
| Upstream sync | `harborctl registry sync <project>/<repo>` | Sync completes; `harbor_upstream_sync_failure_total` stays 0 |
| Authz test | `docker pull <harbor>/<protected-image>` with wrong credentials | `denied`; `harbor_authz_attempt_total{result="denied"}` increments |
| Storage capacity | `kubectl -n harbor describe pvc harbor-storage` | PVC capacity and used%; matches `harbor_repository_total_size_bytes` / `harbor_blob_total_count` |
| HAProxy stats | `curl --user <creds> http://<haproxy>/stats?raw` | Backend status; connection counts; `haproxy_backend_connection_failed_total` |
| Keepalived state | `keepalivedctl status` | VRRP state: MASTER or BACKUP; `keepalived_backend_status` healthy |
| TLS cert expiry | `openssl s_client -connect <harbor>:443 -servername <harbor> </dev/null 2>&1 | openssl X509 -noout -dates` | `notAfter` date displayed; `tls_certificate_expiry_days` calculated |
| Nexus status | `curl <nexus>/service/rest/v1/status` | `200` with component status; Nexus health reported |
