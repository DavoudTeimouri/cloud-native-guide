    Operating Systems¶

    Purpose and scope¶

    Cover supported operating systems: Oracle Linux, RHEL, Rocky Linux, AlmaLinux, Ubuntu Server, Debian, SUSE Linux Enterprise Server, Windows Server. For each: support status, install, offline, hardening, network, DNS/NTP, storage, firewall, packages, kernel, updates, automation, component compatibility matrix, Windows worker node coverage, CIS bypass per role.

    Supported OS matrix¶

    OS Version Kernel Status Supported roles
    Oracle Linux 9.4+ 6.8+ UEK/RHCK Preferred control-plane, worker, storage, LB, repo/registry, GitLab, automation, monitoring
    Ubuntu Server 24.04 LTS 6.8+ GA Preferred control-plane, worker, storage, LB, repo/registry, GitLab, automation, monitoring
    RHEL 9.4+ 5.14+ Supported control-plane, worker, storage, LB, repo/registry, GitLab, automation, monitoring
    Rocky Linux 9.4+ 5.14+ Supported control-plane, worker, storage, LB, repo/registry, GitLab, automation, monitoring
    AlmaLinux 9.4+ 5.14+ Supported control-plane, worker, storage, LB, repo/registry, GitLab, automation, monitoring
    Ubuntu Server 22.04 LTS 5.15 Supported control-plane, worker, storage, LB, repo/registry, GitLab, automation, monitoring
    Windows Server 2022 — Supported worker node only (with containerd)

    OL8 and Ubuntu 20.04 are below Kubespray's 4.19 minimum kernel — not supported.

    Component-to-OS support matrix¶

    Each infrastructure component below lists the OS versions it is certified to run on.

    Component Oracle Linux Ubuntu RHEL/Rocky/Alma Windows Server Notes
    Kubernetes control plane 9.4+ 24.04 LTS, 22.04 LTS 9.4+ No Kubespray requires Linux control plane
    Kubernetes worker (Linux) 9.4+ 24.04 LTS, 22.04 LTS 9.4+ No containerd required
    Kubernetes worker (Windows) No No No 2022 containerd + win-kubelet, Windows containers only
    Ceph MON/MGR/OSD 9.4+ 24.04 LTS 9.4+ No Ceph Quincy/Reef; XFS required
    Ceph RGW 9.4+ 24.04 LTS 9.4+ No Object storage gateway
    Load balancer (HAProxy/NGINX) 9.4+ 24.04 LTS, 22.04 LTS 9.4+ No IP forwarding, keepalived
    Repository/registry (Harbor/Nexus) 9.4+ 24.04 LTS 9.4+ No Large disk for layers
    GitLab 9.4+ 24.04 LTS 9.4+ No omnibus package
    Automation server (Ansible) 9.4+ 24.04 LTS 9.4+ No Python 3, ansible-core
    Monitoring (Prometheus/Grafana/Loki) 9.4+ 24.04 LTS 9.4+ No node_exporter, Loki
    Management server (GUI/admin) 9.4+ 24.04 LTS 9.4+ 2022 Windows for GUI administration

    Per-OS notes¶

    • SELinux (OL/RHEL/Rocky/Alma): enforcing, do not disable
    • AppArmor (Ubuntu): enabled
    • Kernel modules: overlay, br_netfilter, ip_vs, nf_conntrack
    • sysctl: net.ipv4.ip_forward=1, net.bridge.bridge-nf-call-iptables=1
    • Swap: off; transparent huge pages: never

    Windows Server worker node¶

    Windows Server 2022 is supported as a Kubernetes worker node only — not as a control plane node.

    Windows worker requirements¶

    • Windows Server 2022 Datacenter or Standard
    • containerd 1.7+ as the container runtime
    • win-kubelet for Kubernetes node agent
    • Windows containers only (no Linux containers on Windows worker)
    • Hyper-V isolation for container security
    • Join via Kubespray Windows playbook or manual node join

    Windows worker limitations¶

    • No control plane components
    • No Ceph OSD/MON/MDS
    • No load balancer (HAProxy/NGINX/Keepalived)
    • No repository/registry server
    • No GitLab server
    • Linux CNI plugins only; Windows uses HNS or Azure CNI equivalents

    Windows preparation checklist¶

    • Enable Windows Update from internal WSUS
    • Install containerd via Chocolatey or direct MSI
    • Configure Windows Firewall rules for Kubernetes (10250, 3389, 5985)
    • Set page file on dedicated volume
    • Enable BitLocker for OS volume
    • Join domain via Group Policy (not local accounts only — Windows exception)

    Set sticky bit on world-writable directories Keep Keep Keep Keep Keep Keep Keep Keep N/A
    Disable core dumps Keep Keep Keep Keep Keep Keep Keep Keep N/A
    Enable auditd Keep Keep Keep Keep Keep Keep Keep Keep N/A
    SSH: PermitRootLogin no Keep Keep Keep Keep Keep Keep Keep Keep N/A
    SSH: PasswordAuthentication no Keep Keep Keep Keep Keep Keep Keep Keep N/A
