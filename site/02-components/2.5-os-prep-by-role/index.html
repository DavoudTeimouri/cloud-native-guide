    OS Preparation by Role¶

    Purpose and scope¶

    Role-specific OS preparation procedures: general Linux server, K8s control-plane, K8s worker, storage, load balancer, registry manager, GitLab, automation, monitoring nodes. Do not apply identical configurations to every role. Windows worker nodes follow the Windows preparation checklist in section 2.1.

    Common baseline (all Linux roles)¶

    Apply to every Linux node regardless of role:

    1. OS installation¶

    • Install from internal mirror (see section 1.6 for public addresses)
    • Use minimal installation; no GUI packages
    • Set hostname per naming convention: <role>-<cluster>-<index>.<domain>
    • Set root password locked; use admin user with sudo

    2. Package updates¶

    # Oracle Linux / RHEL / Rocky / Alma

dnf update -y --enablerepo=internal-base

# Ubuntu / Debian

apt-get update && apt-get upgrade -y

    3. Users and groups¶

    # Create admin user

useradd -m -s /bin/bash ansible
usermod -aG wheel ansible   # RHEL-family
usermod -aG sudo ansible    # Ubuntu/Debian

# Configure sudo without password for ansible (automation)

echo "ansible ALL=(ALL) NOPASSWD:ALL" > /etc/sudoers.d/ansible
chmod 440 /etc/sudoers.d/ansible

# Set SSH key for ansible user

install -d -m 700 /home/ansible/.ssh
cp <admin_public_key> /home/ansible/.ssh/authorized_keys
chmod 600 /home/ansible/.ssh/authorized_keys
chown -R ansible:ansible /home/ansible/.ssh

    4. SSH hardening¶

    # /etc/ssh/sshd_config

PermitRootLogin no
PasswordAuthentication no
PubkeyAuthentication yes
X11Forwarding no
MaxAuthTries 3
ClientAliveInterval 300
ClientAliveCountMax 0

systemctl restart sshd

    5. NTP / chrony¶

    # Install chrony

dnf install -y chrony   # RHEL-family
apt-get install -y chrony  # Ubuntu/Debian

# Configure internal NTP servers

cat > /etc/chrony.conf <<'EOF'
server 10.10.0.1 iburst
server 10.10.0.2 iburst
allow 10.10.0.0/16
local stratum 10
EOF

systemctl enable --now chronyd
chronyc tracking

    6. DNS¶

    # /etc/resolv.conf or via systemd-resolved / Netplan

nameserver 10.10.0.53
search internal

    7. Kernel parameters¶

    cat > /etc/sysctl.d/99-cloud-native.conf <<'EOF'
net.ipv4.ip_forward=1
net.bridge.bridge-nf-call-iptables=1
net.bridge.bridge-nf-call-ip6tables=1
vm.swappiness=0
vm.overcommit_memory=1
vm.panic_on_oom=0
kernel.panic=10
kernel.softlockup_panic=1
net.core.somaxconn=65535
net.core.netdev_max_backlog=65535
net.ipv4.tcp_tw_reuse=1
net.ipv4.ip_local_port_range=1024 65535
EOF

sysctl --system

    8. Kernel modules¶

    cat > /etc/modules-load.d/containerd.conf <<'EOF'
overlay
br_netfilter
ip_vs
nf_conntrack
EOF

modprobe overlay
modprobe br_netfilter
modprobe ip_vs
modprobe nf_conntrack

    9. Swap and THP¶

    # Disable swap permanently

swapoff -a
sed -i '/ swap / s/^/#/' /etc/fstab

# Disable transparent huge pages

echo never > /sys/kernel/mm/transparent_hugepage/enabled
echo never > /sys/kernel/mm/transparent_hugepage/defrag

cat > /etc/tuned/tuned-thp-no.conf <<'EOF'
[main]
summary=Disable transparent huge pages

[vm]
transparent_hugepages=never
EOF

tuned-adm profile tuned-thp-no

    10. File descriptor and process limits¶

    cat > /etc/security/limits.d/99-cloud-native.conf <<'EOF'
* soft nofile 1048576
* hard nofile 1048576
* soft nproc 65535
* hard nproc 65535
root soft nofile 1048576
root hard nofile 1048576
EOF

    11. Firewall (nftables)¶

    # Install nftables

dnf install -y nftables   # RHEL-family
apt-get install -y nftables  # Ubuntu/Debian

cat > /etc/nftables.conf <<'EOF'
flush ruleset

table inet filter {
    chain input {
        type filter hook input priority 0; policy drop;
        iifname "lo" accept
        ct state established,related accept
        icmp type echo-request accept
        tcp dport 22 accept
    }
    chain forward {
        type filter hook forward priority 0; policy drop;
        ct state established,related accept
    }
    chain output {
        type filter hook output priority 0; policy accept;
    }
}
EOF

systemctl enable --now nftables

    12. Auditd¶

    dnf install -y auditd   # RHEL-family
apt-get install -y auditd  # Ubuntu/Debian

systemctl enable --now auditd

    13. AIDE (file integrity)¶

    dnf install -y aide   # RHEL-family
apt-get install -y aide  # Ubuntu/Debian

aide --init
mv /var/lib/aide/aide.db.new.gz /var/lib/aide/aide.db.gz

    14. Unattended security updates¶

    # RHEL-family: dnf-automatic

dnf install -y dnf-automatic
sed -i 's/apply_updates = no/apply_updates = yes/' /etc/dnf/automatic.conf
systemctl enable --now dnf-automatic.timer

# Ubuntu: unattended-upgrades

apt-get install -y unattended-upgrades
dpkg-reconfigure -plow unattended-upgrades

    15. CA bundle¶

    # Copy internal CA to trust store

cp <internal_ca.crt> /etc/pki/ca-trust/source/anchors/
update-ca-trust extract   # RHEL-family

# or: update-ca-certificates   # Ubuntu/Debian

    16. Containerd prerequisites¶

    dnf install -y containerd conntrack ethtool   # RHEL-family
apt-get install -y containerd conntrack ethtool  # Ubuntu/Debian

    Role-specific preparation¶

    Control plane nodes¶

    • Common baseline +:
    • Dedicated NVMe for etcd (mounted at /var/lib/etcd, XFS, noatime)
    • max_pods: 110
    • kubelet reserved CPU/memory
    • Reserved system resources

    Worker nodes¶

    • Common baseline +:
    • Container runtime (containerd) configured
    • kubelet installed and configured
    • Node labels and taints applied
    • GPU drivers (if GPU worker)

    Storage nodes (Ceph)¶

    • Common baseline +:
    • XFS with ftype=1 for OSD devices
    • Dedicated journal/WAL devices (NVMe)
    • Disk tuning: readahead, scheduler
    • Ceph user and group

    Load balancer nodes¶

    • Common baseline +:
    • IP forwarding enabled
    • keepalived installed and configured
    • HAProxy/NGINX installed
    • VIP health checks

    Registry/registry manager nodes¶

    • Common baseline +:
    • Large disk for image layers (/var/lib/registry or /opt/registry)
    • Backup configuration
    • TLS certificates

    GitLab nodes¶

    • Common baseline +:
    • PostgreSQL, Redis configured
    • Object storage bucket
    • GitLab omnibus package

    Automation nodes¶

    • Common baseline +:
    • Ansible venv at /opt/ansible/venv
    • Collections from internal Galaxy mirror
    • SSH keys for all managed nodes
    • known_hosts pre-populated

    Monitoring nodes¶

    • Common baseline +:
    • node_exporter installed
    • Fluent Bit installed
    • Prometheus scrape targets configured

    CIS bypass per role¶

    See the CIS bypass table in section 2.1. Apply "Keep" controls unless the role-specific bypass column indicates otherwise.

    Validation¶

    # Verify OS preparation

chronyc tracking
nft list ruleset
auditd status
swapoff --show
cat /sys/kernel/mm/transparent_hugepage/enabled
sysctl net.ipv4.ip_forward
lsmod | grep -E 'overlay|br_netfilter|ip_vs|nf_conntrack'

    Automation: OS preparation playbook¶

    Run the full OS preparation via Ansible instead of manual commands:

    # Dry-run (recommended first)
ansible-playbook -i automation/ansible/inventories/staging/hosts.ini \
  automation/ansible/playbooks/os-prep-base.yml --check --diff

# Apply to production
ansible-playbook -i automation/ansible/inventories/production/hosts.ini \
  automation/ansible/playbooks/os-prep-base.yml

# Limit to specific role
ansible-playbook -i automation/ansible/inventories/production/hosts.ini \
  automation/ansible/playbooks/os-prep-control-plane.yml --limit k8s-control-plane
ansible-playbook -i automation/ansible/inventories/production/hosts.ini \
  automation/ansible/playbooks/os-prep-worker.yml --limit k8s-workers
ansible-playbook -i automation/ansible/inventories/production/hosts.ini \
  automation/ansible/playbooks/os-prep-storage.yml --limit ceph-nodes

    Customization variables (automation/ansible/group_vars/all/main.yml):

    Variable Default Customize when
    ntp_servers 10.10.0.1, 10.10.0.2 Your internal NTP differs
    dns_servers 10.10.0.53 Your internal DNS differs
    admin_user ansible You use a different admin name
    swap false Never set to true for K8s nodes
    selinux enforcing Set to permissive only for troubleshooting

    Windows worker node preparation — see automation/ansible/playbooks/os-prep-worker.yml (Linux) and the Windows preparation checklist in section 2.1. Windows worker nodes use PowerShell DSC/WinRM instead of Ansible SSH.
