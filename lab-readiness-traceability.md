## Critical Blockers — Must Resolve Before Lab Deployment

The following prerequisites must be satisfied before any lab deployment can begin. These are ordered by dependency chain:

1. **K8s control-plane bootstrap** — etcd quorum and API server health (Component #3). Without this, no other component can be validated. *Blocking all downstream components.*

2. **CNI installation and network validation** — Cilium (or Calico) must be running and pod-to-pod connectivity confirmed (Component #5). *Blocks: Ceph/Rook, Rancher, Argo CD, Ingress, Security policies, all workload scheduling.*

3. **OS compatibility confirmed** — kernel version, SELinux mode, package manager, and unattended update source must match the kubespray release (Component #2). *Blocks: all K8s node operations.*

4. **Storage (Ceph/Rook) device availability** — OSD devices must be present and formatted; MON quorum must be achievable (Component #6). *Blocks: stateful workloads, CSI provisioning, persistent volumes for databases and registries.*

5. **Container registry (Nexus/Harbor) infrastructure** — underlying storage, PostgreSQL, TLS certs, and mirrored artifact repository must be operational (Component #8). *Blocks: image pulls for K8s addons, CI/CD pipeline functionality, offline-capable cluster operation.*

6. **Load balancer VIP and Keepalived configuration** — VIP assigned, health check targets defined, VRRP peer link up (Component #9). *Blocks: API server access via VIP, ingress controller frontend, all external traffic flow.*

7. **Observability stack minimal deployment** — Prometheus + Grafana + Alertmanager with local TSDB (Component #10). *Blocks: SLO tracking, error budget visibility, alert-driven incident response during lab validation.*

8. **Identity and secrets bootstrap** — etcd available as Vault backend storage; PostgreSQL for Keycloak; Vault initialized with unseal keys (Component #12). *Blocks: service account secret injection, authentication for all downstream services, RBAC token generation.*

9. **GitOps and Argo CD deployment** — K8s API healthy, GitLab repo accessible (mirrored), cert-manager bootstrapped (Component #13). *Blocks: application deployment workflow, progressive rollouts, GitOps-driven lifecycle management.*

10. **Security policy admission enforcement** — OPA/Gatekeeper constraints compiled and bound; PSS restricted baseline active (Component #14). *Blocks: any pod scheduling without approved security context; admission webhook rejection of non-compliant manifests.*
